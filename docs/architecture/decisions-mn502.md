## 二、自有增强（MN5 5.0.2 无此能力或未观察到，不与 MN5 对照验收）

| 能力 | 依据 | 说明 |
|---|---|---|
| **同步状态中心**（等待上传/进度/冲突面板） | D-04：MN5 只有「云同步」设置（CloudKit/不同步两行单选），无状态面板 | 明确标注为超出 MN5 的自有能力 |
| **PDF 合并三选项**（当前页/页范围/整本） | D-05：MN5 只有「追加到末尾」「拼成新文档」两档 | 保留但视为增强 |
| **目录键盘矩阵**（↑↓/Alt+方向/空格/Enter） | D-26：三条路径均未观察到目录接受键盘导航 | 标注为自定义实现，不宣称对齐 |
| **状态栏三态**（full/compact/hidden） | D-32：五页设置+右键+显示菜单均 absent；模板 schema 也无 statusBar | 自有扩展 |
| **长图分段导出**（parts + 按段分页） | D-11：MN5 用滚动，不生成超长图 | parts 仅用于导出，属实现选择 |
| **手写绑定模型**（画在卡上自动绑定） | D-27：MN5 是显式选择「跟着选中/不绑定/固定到某卡」 | 交互模型差异，需评估是否改写 |

## 三、未取得（inconclusive，不得当「不支持」）

| 项 | 原因 |
|---|---|
| 目录键盘焦点 | 三条路径均未建立焦点（D-26） |
| 笔迹解绑入口 | 未能构造出与卡片绑定的笔迹（D-25） |
| 缩放比例菜单 / 缩放按钮 / 独立翻页按钮 | 未找到（D-18/D-31） |
| 多文档书脊搜索 | 只测单文档（D-33） |
| 深色模式全页 | 只截部分（C8） |
| 21 个设置页逐项行为 | 只做了控件清单（D1 设置矩阵） |
| PencilKit 笔画点/压感解码 | 需 PencilKit 运行时，静态不可解 |
| 摘录坐标语义（page 基/单位） | 未确认 |

## 四、结论

- **对齐项**：以 D-01~D-23 + D1 运行时数据为准，实现已按此修正（I-01~I-22）。
- **增强项**：第二节 6 项在产品说明里必须标「自有增强」，不与 MN5 对照验收。
- **未取得项**：只能用现有合成证据，禁止宣称「MN5 不支持」。
