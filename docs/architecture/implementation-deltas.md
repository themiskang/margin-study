## P0 · 语义错误（我们做的和 MN5 不一样）

### I-01 · 摘录提示按钮（D-01）

- **MN5**：纯文档视图时提示为「已加入脑图 / **打开脑图** / 撤回 / 摘录操作 / 摘录去向」；
  分屏时**没有**「打开脑图」按钮；新卡在视野外会自动滚动并选中。
- **我们**：`excerptNotice` 提供「定位」，任何视图都显示。
- **改法**：
  1. 文案「定位」→「打开脑图」
  2. 仅在脑图不可见时渲染该按钮
  3. 分屏时不渲染
  4. 新卡入图后若不在视野内，自动滚动居中 + 选中
- **验收**：纯文档摘录出现「打开脑图」；分屏摘录不出现；点击后切分屏并选中新卡；视野外自动滚动。

### I-02 · 连续摘录合并（D-02）

- **MN5**：连续摘录显示「…1 段 → 2 段」，结束时提示「**已合并 2 段 ✓**」，生成**一条**摘录。
- **我们**：待核；若产生多条独立摘录则为不一致。
- **改法**：连续摘录期间累积，结束时合并为单条 annotation（保留分段矩形）。
- **验收**：连续摘两段后 annotation 数量 +1，rects 长度 +2。

### I-03 · 撤回语义（D-03）

- **MN5**：点「撤回」提示「**已撤回入图，原文摘录保留**」。
- **我们**：待核；若删除摘录本身则为不一致。
- **改法**：撤回只移除脑图节点/入图关系，保留 annotation。
- **验收**：撤回后 annotation 仍在，节点消失。

### I-04 · 长复习卡显示策略（D-11）★影响最大

- **MN5**：复习界面卡面为**固定视口 + 内部滚动**；评分按钮固定在卡外。
- **我们**：`V02-REVIEW-LONG` 生成 `parts` 分段 + 数万像素长图，导出按段分页。
- **改法**（方向性）：
  1. 复习界面改为「固定高度卡面 + 内容区 overflow 滚动」，不再按段渲染长图
  2. 笔迹坐标改为相对内容坐标，滚动时跟随
  3. `parts` 机制保留用于**导出**，但不再是展示主路径
- **验收**：30000px 内容卡在复习界面可滚动到底、评分按钮始终可见、笔迹随内容滚动。

### I-05 · 节点折叠展开（D-08）

- **MN5**：点折叠点收起；**再点不展开**，需画布菜单「全部展开」。
- **我们**：再点一次即展开。
- **改法**：再点折叠点保持收起（或改为无操作）；画布菜单提供「全部展开」。
- **验收**：收起后再点仍为收起；菜单「全部展开」恢复。

## P1 · 缺失能力（MN5 有我们没有）

### I-06 · 界面模板「绿色」（D-15）

- **MN5**：白色 / 棕褐色 / 灰色 / 暗黑 / **绿色**
- **改法**：补绿色主题变量，五色齐备。
- **验收**：设置里 5 个模板可选，切换后阅读器配色同步。

### I-07 · 阅读模式：竖向 / 翻页（D-16）

- **MN5**：「页面与显示」含 竖向阅读 / 翻页阅读 / 双页模式(PDF) / 裁边 / PDF OCR设置 / 编辑PDF页面
  - 双页模式是**全局开关**，操作后提示「对所有学习集生效」
  - 竖向阅读时双页**禁用**并提示先切回翻页
- **改法**：补阅读模式枚举（vertical/paged）；双页开关改为全局并给影响范围提示；竖向时禁用双页。
- **验收**：两模式可切换且状态持久；竖向时双页禁用有提示；关闭双页提示影响所有学习集。

### I-08 · 复习快捷键（D-12）

- **MN5**：空格翻面；**背面** `1/2/3/4` = 重复/难/良好/易；正面按数字无效
- **改法**：绑定按键，加「仅背面生效」守卫。
- **验收**：正面按 1–4 无反应；背面按 1 评分「重复」，其余对应。

### I-09 · 复习收尾界面（D-09）

- **MN5**：评完最后一张显示「已到最后一张卡片」+「从头再来一遍」/「完成」
- **改法**：补收尾态。
- **验收**：最后一张评分后出现该界面，两个按钮可达。

### I-10 · 脑图连线交互（D-13）

- **MN5**：选中节点 → 点工具条「链接」→ 源节点出现**大号链条图标** → 从链条拖到目标
  - 拖「链接」按钮本身无效
- **改法**：点击「链接」后渲染可拖拽的链条锚点；拖拽从锚点起算。
- **验收**：点链接后节点出现链条；从链条拖到目标生成连线；从按钮拖不生成。

### I-11 · 多选工具条 11 项（D-06）

- **MN5**：剪切、复制、颜色、标签、链接、概要、重组、合并、对话、删除、更多
- **改法**：核对我们的多选工具条项与顺序，一致化。
- **验收**：多选后工具条项与顺序完全一致。

### I-12 · 画布右键菜单（D-07）

- **MN5**：新建卡片、粘贴、排列、缩放至合适大小、展开到层级
- **改法**：核对我们的画布菜单；节点上**不要**提供专属右键菜单（D-14 未观察到）。
- **验收**：空白处右键 5 项一致；节点右键不弹专属菜单。

## P2 · 需重新定性（不是对齐项）

  **没有**上传队列/进度/冲突面板。
- **结论**：我方 `V02-SYNC-CENTER` 的「同步状态中心」是**增量功能**，不是 5.0.2 对齐项。
  应在文档与产品说明中明确标注为「超出 MN5 的自有能力」，不与 MN5 对照验收。

### I-14 · PDF 合并选项（D-05）

- **MN5**：只有「追加到《X》末尾」「和《X》拼成新文档」两档；未发现页范围选择。

### I-15 · 目录键盘（D-17）

  不宣称对齐。

## P1 补充（来自 C9，D-19 ~ D-25）

### I-16 · AI 面板（D-19）

- **MN5**：`immersiveAI` 入口；面板含「更多 AI 功能 / 对话 / 模板 / 输入框 / 发送」
  - 模板：**无 / 引导模式 / 测验模式 / 解释模式 / 整理成脑图** + 管理
  - 更多：对当前文档、《AI 生成目录》
  - 提示：可拖入卡片/选区/文本/图片；回复可拖到脑图生成卡片
- **改法**：核对我们的 AI 面板模板集合与「AI 生成目录」能力；缺则补。
- **验收**：模板 5 项齐全；有「AI 生成目录」入口；拖入/拖出提示文案一致。

### I-17 · 学习集导出（D-20）

  补「历史版本」选项。

### I-18 · 导入四路（D-21）

### I-19 · 套索工具条（D-22）

### I-22 · 场景模板真实 schema（D1 实测，替代界面反推）

来源：`evidence/mn5-5.0.2-data/SCENE-TEMPLATES.md`（`~/mn5data/Documents/ImmersiveTemplates/*.json`）

**MN5 顶层键**：`bottom`, `coach`, `home`, `id`, `name`, `plugins`, `resume`, `review`, `schema`, `surfaces`, `toolbar`

| 维度 | MN5 实际 | 我方现状 |
|---|---|---|
| 场景划分 | `toolbar.tabs: ["read","write","recall"]` + `bottom.modes[].behavior` | `scenes[]` 6 个（reading/excerpt/handwriting/writing/organize/recall） |
| 工具 | `modes[].tools[]`（recall 有 `recall.level/reset/hint/settings/handwrite`、`pref.reviewAutoAdd`） | `scenes[].tools[]` 字符串 |
| 溢出菜单 | `modes[].overflow[]`（`act.* / pref.* / choice.* / panel.*` 前缀） | 无独立 overflow 概念 |
| 表面 | `surfaces: {bottomRead:{visible:[theme,titleLinks,blockSelect]}, dock:{visible:[contents,ai,research]}, dockPinned:[contents,ai], excerptResultBar:true}` | 无 |
| 复习规则 | `review: {autoAdd:"off", rule:{excludeGroupChildren:true, excludeToc:true}}` | `auto-review` 开关 |
| 恢复 | `resume: {card:"silent"}` | 无 |
| 教练 | `coach: {enabled:false}` | 无 |
| 状态栏 | **无 `statusBar` 字段** | `statusBar: full/compact/hidden`（D-32 已证 MN5 无） |
| schema 版本 | `schema: 3` | 无版本字段 |

**改法**：`StudySceneTemplate` 增 `schema` / `surfaces` / `review.rule` / `resume` / `coach` / `modes[].overflow`；
`statusBar` 保留但标注为自有扩展。动作 id 命名对齐 `act.* / pref.* / choice.* / panel.* / tool.*` 前缀。

**验收**：导入 MN5 的 `standard.json` 后，我方模板不报错且字段可回写；
导出我方模板能被 MN5 语义接受（至少 schema 字段齐全）。
