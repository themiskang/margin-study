# 编辑后 PDF 导出验收（11.6）

更新：2026-10-19。已完成下列实现与插件验证，仅部署到 MarginStudy验收库。11.6 的原版等价验收仍有缺口，父项11保持未完成。

## 本轮实际新增

“学习集与文档 → Export Document…”及命令“导出编辑后的 PDF”打开全屏选页。提供 Cancel、Export(n)、Contents、All Pages、Page Range、Annotated、Clear、蓝色圆勾及实际编辑结果的缩略图。默认全选，空选禁止导出，非法范围显示错误。格式面板提供 PDF；Long Image 当前禁用，尚未实现。

PDF 按当前页序包含原页、独立导入PDF/图片PDF、空白页、移动、删除、旋转及全页裁边/扩页。源文字和矢量通过复制PDF页保留；默认固化当前可见的插件批注，隐藏笔记本/图层不导出。高亮、下划线、删除线、区域及笔迹使用矢量；中文富文字和自由图片仅将批注区域转换为透明PNG，不栅格化整页。语音目前仅导出点标记，不嵌入音频，图标未等价。

构建完全在内存中进行；支持选页、关闭批注和取消信号，拒绝并发导出、无效页码、缺失来源及切文档/改页/改裁边后的迟到结果。macOS使用Obsidian提供的Electron系统保存面板，先写同目录临时文件，再原子发布新文件并清理临时文件。已有目标一律拒绝覆盖，即使系统面板选择Replace也不能替换；这是当前与原版/系统保存期望的差异。

未提供系统面板时使用库内 `MarginStudyExports/` 备用保存。补充回归复现了“存储检查期间Cancel仍迟到写文件”，已修复：取消后每个异步检查返回都重新确认窗口有效。最终 `createBinary` 写入一旦开始便无法中止，期间禁用Cancel并阻止Esc/点背景关闭；完成后报告真实结果。备用路径已在隔离浏览器验证取消及重新保存可读PDF，尚未在没有原生面板的真实宿主中单独验收。

## 原版 L4 依据及边界

本轮实际操作原版4.4.6的 **File → Export → Export Document**，确认选页、Clear禁用、Annotated选中该样例1页、Page Range文案、PDF/Long Image/Cancel格式选择，以及带Flatten默认名的系统Save，并保存真实四页输出。Contents打开显示 `p.1–4, Pages 1-4`；未点击此范围核对结果。

原版输出四页、文字可提取，该样本没有交互Annots；页尺寸约768×993.8824，横页768×593.4545，Rotate=0。插件保留源页尺寸和Rotate，两者输出尺寸策略不同。未在原版完成相同编辑组合、全部批注、复杂目录、长图和保存替换规则的实测，不能从当前样本推断这些行为。插件入口也未与原版系统File菜单等价；没有将其加入Document - More冒充已确认入口。

## 验证与修复

- 红→绿记录包括导出方法、可见批注、中文批注缺失、选页UI、迟到结果保护和备用保存取消竞态。最终 `node scripts/verify.mjs typecheck build reader workspace`：Reader **115/115**、Workspace **80/80**，类型检查与构建通过。该数字不代表MN4覆盖比例。
- 隔离回归覆盖编辑页序/删除/空白/导入、固有旋转与额外旋转叠加、内裁/外扩、非零CropBox、排序去重、源文字可选、隐藏笔记本、中文/笔迹投影，以及取消/并发/缺源/切文档保护。自由图片导出像素、全部富文本样式和真实音频标记尚无专项验收。
- 实机首次格式弹层在截图中存在，但AX仍停留下层；已定位为子弹层落在全屏aria-modal范围外，修复嵌套及焦点后，真实AX可读、PDF按钮和系统保存通过。没有归因于网络或用户切屏。
- 验收库真实组合：四原页加入矢量测试页和空白页，移动、旋转后导出六页；裁边另存，独立解析页序/Rotate/CropBox和可选文字，并用Poppler渲染全部六页查看。macOS“预览”重新打开裁边输出，显示Page 2 of 6、旋转后的导入文字和红蓝矢量矩形。
- 第一份六页文件实际未裁边：直接点击手柄未获得键盘焦点。该失败保留；随后通过Tab获得手柄焦点、实际改变裁边，第二份 `MarginStudy-cropped-export.pdf` 才是裁边通过证据。未改写第一份文件。
- 最终取消修复构建已真实停用/启用，确认启用列表落盘，再重开工作区并通过系统Save写出四页最终PDF。没有重新编译/重签名相机或改动相机权限。

源第3页原有内容流含非法 `0 rg`，Poppler会报告“Too few (1) args to 'rg' operator”；输出保留同一源流。渲染已检查，未发现新缺损，源文件未修改。
