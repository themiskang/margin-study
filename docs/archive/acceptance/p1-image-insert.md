# 图片插页阶段验收（11.5，部分完成）

更新：2026-10-19。开发版仅部署到 MarginStudy验收库，11.5及父项11保持未完成。

已实现 Files 选图片后直接插到当前页之后，不进入PDF缩略图选择器；Photos 当前支持从本地文件选择一张或多张图片，按选择顺序逐张插页。每张图片保持自然宽高比，转换为库内独立PDF附件，原PDF不改写。取消不提交；整批图片全部解码成功后才提交，坏图片和读取期间切换文档不改页数据、不留下附件。原始图片移走后可继续阅读及重开。

原版L4已确认 Files 可选PNG，直接插在当前页后、保持宽高比并定位新页。原版 Photos 打开系统照片选择器，本机图库显示 No Photos，未成功选图；Camera 能打开实时相机预览，未拍照，用户已取消。不把无照片或未拍照记为插入成功。官方手册缓存见 `evidence/official-sources/manual-adding-deleting-pages-cropping-page.json`。本项没有直接对应的Qoder六专题L3契约，以上原版行为来自本轮实机观察。

插件真实Obsidian验证：Files插入360×240红蓝合成图，四页变五页，新页为第3页；将来源PNG移入证据目录后，实际停用/启用插件并重开工作区，图像和页身份仍在。Photos当前本地文件入口再次插入合成图，五页变六页，无PDF选页弹窗。最后通过Remove Page移除第6页及第3页，并用Go to Page返回第1页。两份测试来源均收存到证据目录；库内导入附件保留，当前文档无插页引用。

实机发现 Add Page 菜单靠近底边时被阅读区遮挡。新增行为回归先失败（菜单底部482，阅读区底部441），修复后按阅读视口定位，优先显示在按钮上方，空间不足时内部滚动；随阅读区滚动/缩放尺寸重新定位，并在关闭时移除监听。真实底边截图12显示三项完整可见。窄短视口的末项可达性由隔离回归覆盖，未声称全部宿主窗口尺寸均已实测。

最终针对性检查 typecheck、build、Reader97/97、Workspace80/80通过。Reader使用真实PDF.js解析和渲染合成文件；宿主API用适配器隔离，真实Obsidian结果另列上文。最终22/22限定比较通过：全部业务模型区段、设置、docMeta及完整workspaceState恢复图片阶段前基线，原PDF与两处受保护main.js哈希不变。revision、writerId、savedAt是正常保存元数据，不声称整份data.json字节不变。开发与验收库四产物哈希一致；未复制AI配置。

剩余差距：Photos当前为系统文件选择器，尚非原版直接进入的Apple Photos图库；Camera入口/拍照插页及iPhone连续互通未实现。支持PNG/JPEG/WebP/GIF/BMP/AVIF的浏览器静态解码，HEIC未支持，动画不拆多帧。单批1—100张、单文件100MB、单图32MP、总64MP及边长14400是当前实现限制，未确认与原版相同。透明像素合成白底、EXIF方向应用、复杂色彩/格式与全尺寸视觉仍需对照，不能据此宣称与MN4完全一致。
