更新：2026-10-19。Normal/Margin/Collapse 的基础实现和下列插件验证已通过，仅部署 MarginStudy验收库。11.8 和父项 11 保持未关闭；下一步仍在 11.8 补留白摘录、卡片关联和完整菜单，不跳到 11.9。

## 已实现

顶部留白工具可在 PDF 页中创建文字留白，Document - More 新增 Normal/Margin/Collapse 三段选择。Normal 在原文之间插入实际空白，正文、文字选择层、批注、手写及语音投影随之移动；Margin 将相同留白放到页边，正文不增加高度；Collapse 显示虚线入口，点击打开浮动文字编辑框。已有页内富文字编辑器支持留白文字编辑、保存及重开。

留白支持独立手写、荧光、橡皮及套索；位置和高度可拖动，创建/编辑/笔迹/移动/高度/删除进入现有统一 Undo/Redo。数据使用插件自己的文档笔记本元数据和稳定页 ID；原 PDF、原有批注 sidecar 及原坐标不迁移。跨文档前完成草稿保存，其他窗口已更新的文字不会被迟到草稿覆盖。删页后留白暂隐藏，恢复同一页 ID 后再现。

导出可包含展开后的留白文字和笔迹；原正文按带分段嵌入，保持原文字可提取。留白文字当前栅格化、笔迹矢量输出。导出同时检查文档、页编辑、留白及笔记本是否变化。这是当前插件的输出策略，未声称等同原版导出策略；本轮留白导出仅通过隔离自动验收，未做真实宿主系统保存。
