# PDF 页编辑撤销与删除页恢复验收

更新：2026-10-19。子项 11.7 的列明实现与插件验证通过，仅安装到 MarginStudy验收库；父项 11 和整插件原版等价保持未完成。下一子项 11.8 Extend Normal/Margin/Collapse。

## 新增行为

插空白页、PDF/图片插页、移动、旋转、删除已加入阅读区顶部 Undo/Redo，与手写和自由批注共用按时间排序的历史。新操作清除重做分支；异步撤销期间按钮禁用，重复请求不重放。保留原版已观察的顶部按钮入口，没有新增未经核实的“恢复删除页”菜单。

页面按插件自己的稳定 ID 恢复，原始 PDF 和批注坐标不改写。恢复删除页时补回该页的书签/折叠状态及各笔记本对应状态，保留存活页上后来的选择。撤销重建纸面后页编辑控件继续可用。恢复前验证独立导入附件，缺失时保留当前可用文档并提示，不提交不可用的页记录。

历史只在当前阅读器会话中存在；切文档、插件重载、关闭及冲突会清除。退出页编辑后插件仍可撤销/重做，并保持退出状态；原版退出后保留历史的行为尚未确认。
