# P1 系统图库与相机插页阶段记录

2026-10-19。仅部署 MarginStudy验收库；11.5及父项11保持未完成。

## 本轮交付

- macOS Photos 入口改用官方 PHPickerViewController；只接收用户选择的照片临时副本，按选择顺序转为PNG，再沿现有图片插页通路保存为库内独立附件。
- 随插件构建原生辅助组件，使用公开 PhotosUI / ImageIO API。当前构建为本机 arm64，要求 macOS 13+；其他架构尚未验证。没有枚举整座图库。
- 取消、关闭页编辑或切换文档会终止图库请求并清理临时目录；校验结果协议、文件名、大小及图片尺寸，禁止返回任意路径。
- 保留已有相机初稿，补上等待权限后取消、编码后取消、Esc误关底下页编辑、设备请求乱序等保护。新增复现并修复切换设备期间仍能抓旧帧：启动期间禁用Capture并清空旧流。
- 菜单顺序为 Blank / Files / Photos / Camera。
