# 对话 05：卡组与复习完整流程

这是可以直接交给新对话执行的任务书。先读 [共用规则](00-总控与交接规则.md) 和 [实时清单](../后续工作清单.md)，然后实施本包；不读取整个旧聊天。

## 范围（原清单 10、18—20）

卡组浏览、问题、答案、评分、完成页和各自底栏；首末张/空组/筛选/模板/成员刷新/字词与自由遮挡；四档评分、到期与历史。

重点保留用户反复指出的“刚打开问答评分卡组之前的浏览页”正确底栏，不能只验证评分页面。按 Qoder 复习/遮挡 L3 契约及原版 L4 验证；当前独立 FSRS 参数不等于原版权重。

## 按需读的代码

src/review/；src/cards/nativeEditor.ts；src/model/store.ts；src/annot/ 中遮挡/回忆逻辑；src/study/；复习 nativeStage/presentation/templates。

以上路径均相对开发目录 `${MARGINSTUDY_REPO}`；只读取本次需要的文件和函数，不批量输出整个目录。

## 具体关闭要求

从组列表→浏览→问题→答案→四档评分→完成→返回完整走通；首末/空组/筛选后成员变化、复制刷新不污染独立复习状态；遮挡与源文缩放定位一致；保存重开与历史核对。

同时满足共用规则的功能、呈现、数据、证据和保护要求。现有能力先核对，补差距并完成整包流程；对不确定原版规则做针对性实测。完成当前改动后跑适当自动检查、build、验收库真实宿主验证，清理合成测试内容。
