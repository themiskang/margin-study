# MN5 5.0.2 全范围取证计划 v2（目标：对齐 5.0.2 不再需要打开 MN5）

**版本基准：** 固定 **5.0.2**，不追新版本
**最终目标：** 此后插件对齐 5.0.2 时，**不需要再启动 MN5**
**已有资源：** 用户有 Pad（压感/真笔实测）、REa（数据层逆向）、Obsidian 隔离库可常开

---

## 0. 目标可达性（基于用户补充的资源）

| 此前的硬边界 | 现在的解法 |
|---|---|
| 新版本过期 | 用户：只以 5.0.2 为基准 → **消除** |
| 压感/笔迹物理特性 | 用户有 Pad → 单独一包 **P1**（需用户配合，见 §4） |
| 数据层 schema | 用户有 REa → 单独一包 **D1**（逆向，见 §3） |
| 真实运行环境 | Obsidian 常开 → 对照走 Obsidian 侧，无需 MN5 |

**结论：C1–C5 + D1 + P1 全部完成后，对齐 5.0.2 不需要再打开 MN5。**
其中 D1 和 P1 可以**晚于试用期**做（数据文件与 Pad 不依赖试用有效性），
但 C1–C5（界面行为）必须在试用期内采完。

## 2. 状态穷举（并入 C1–C5，不另起包）

每个功能面**必须**同时采以下状态，缺的标 `absent`：

- 默认态
- 空态（无数据）
- 满态（数据多/长文本/多图）
- 选中态 vs 未选中态
- 禁用态（按钮灰掉 + 原因 tooltip）
- 错误态（若可安全触发，如打开不存在文档）
- 加载中（若可观察）

> 这些边角状态过期后无法补，且是 UI 实现最容易漏的部分。

## 3. D1 · 数据层逆向（REa，可在试用期后做）

**目标：** 拿到 5.0.2 的真实持久化 schema，使导入器/数据模型对齐不依赖界面猜测。

### 范围

1. 定位 MN5 容器：`~/Library/Containers/<bundle>/Data/Documents/` 下的学习集文件
2. 用 REa 打开并导出结构：
   - SQLite 表清单 + 每表字段 + 类型 + 主外键
   - Plist/二进制块（若有）中的卡片、节点、批注、笔迹矢量、复习调度
3. 与我方 `src/types.ts` 的 `Card` / `MindmapNode` / `Annotation` / `Media` / `CardState` 做字段映射表
4. 重点回答：
   - 笔迹矢量怎么存（点序列？压感数组？坐标系原点？）
   - 节点父子关系与脑图布局怎么存
   - 复习调度（FSRS/SM2）参数与状态字段
   - 摘录与源文档的锚定方式（页码/偏移/矩形）
   - 手写与卡片的绑定字段（对应我方 `focusNodeId`/`targetCardId`/`targetFrame`）

### 产物

- `evidence/mn5-5.0.2-data/SCHEMA.md`：表与字段完整清单
- `evidence/mn5-5.0.2-data/FIELD-MAP.json`：MN5 字段 ↔ 我方类型字段的映射（含未知字段标注）
- `evidence/mn5-5.0.2-data/SAMPLES/`：每类实体的真实样本（脱敏）

### 完成定义

- 每类核心实体（卡片/节点/批注/笔迹/复习）都有完整字段表
- 映射表里每个字段标注 `direct`（一一对应）/ `derived`（需计算）/ `unknown`（我方没有）
- 我方缺失的字段单列「对齐时需新增」

## 4. P1 · Pad 压感与真笔（需用户配合）

**目标：** 拿到数位笔/Apple Pencil 的真实行为，供手写实现与验收使用。

### 需要用户做的（届时我会给明确步骤）

1. Pad 与 Mac 配对（随航 Sidecar 或直接 Pad 上装 MN5）
2. 用 Apple Pencil 按指定动作书写（轻/重/快/慢/倾斜）
3. 触发掌触抑制场景（手掌放屏上同时用笔）
4. 双击笔身切换工具（若 Pencil Pro）

### 采集内容

- 压感 → 笔迹粗细的映射曲线
- 掌触抑制表现（哪些事件被吞）
- 随航下的事件延迟与坐标系
- 双击切换的行为

### 产物

- `evidence/mn5-5.0.2-pen/PEN-PHYSICS.md`
- 视频/连拍 + 参数表

> 这部分不依赖 MN5 试用，可在之后任何时间做。
> 若用户 Pad 上是 MN5 试用版且已到期，可用**我们自己的插件**在 Pad 浏览器/Obsidian 上测，
> 但需另行说明「非 MN5 原生」。
