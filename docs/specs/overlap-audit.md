# POLISH-1b 遮挡审计

数据来自隔离 Obsidian 宿主的 CDP `document.elementsFromPoint`。
截图与原始采样位于 `.agent-artifacts/polish1b-*`。
三种尺寸由 CDP 模拟，非调整原生窗口尺寸。

| 位置 | 被遮挡元素 | 遮挡元素 | 严重度 | 状态 |
| --- | --- | --- | --- | --- |
| 三种视口的顶部 | 当前文档按钮 | 简洁显示把手 | 影响 | 把手移至左上角；最终样本命中把手自身 |
| 工作区底部 | 看板操作 | Obsidian 状态栏 | 阻断 | 预留 28px；三个看板按钮中心点均命中自身 |
| 756×427 | 隐藏脑图按钮 | 底部工具胶囊 | 影响 | 上移分隔栏按钮；最终样本命中按钮自身 |
| 756 宽度的文档页签 | 文档标题和附件按钮 | 相邻页签 | 影响 | 页签改为至少 76px 的 flex 基准，超出时横向滚动；最终宽度 76px，仍须逐按钮复测 |
| 三种视口的主页 | 主页控件中心点 | 无 | 已采样 | 无中心点遮挡 |
| 三种视口的复习卡组选择 | 卡组选择与操作 | 无 | 已采样 | 所有控件中心点命中自身 |
| 三种视口的复习评分 | 评分与操作按钮 | 无 | 已采样 | 使用隔离库测试卡，所有可见按钮中心点命中自身 |
| 756×427 同步面板 | 底部操作 | 面板滚动区域 | 轻微 | 初始位于可见区外；滚至底部后三个按钮均命中自身 |
| 三种视口的简洁显示 | 目录与缩略图页签 | 简洁显示把手 | 影响 | 简洁显示中将把手移至中央；五个页签及把手均命中自身 |
| 三种视口的卡片手写撤销 | 撤销与关闭提示 | 无 | 已采样 | 保存隔离测试笔画后，两个按钮均命中自身；短视口未发现编辑器按钮中心被遮挡 |

滚动容器中不可见的控件中心点不计为遮挡；须滚动后单独验证可达性。
修复前截图为 `polish1b-workspace-*`，修复后为 `polish1b-final-*`。

复习卡组选择和同步面板的数据见 `polish1b-modal-samples.json`。
