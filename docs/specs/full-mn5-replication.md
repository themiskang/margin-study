# MN5 全量复刻目标与差距矩阵

> **当前目标版本：MN5 5.0.2（2026-11-10 用户确认）**。5.0.0 的旧菜单/几何证据仅用于回归，不作为 5.0.2 验收证明。增量计划与状态见 `docs/specs/mn5-5.0.2-delta.md`。
>
> 2026-11-10 用户明确：不以路线 A / 路线 B 为边界，目标是全功能、全部表面、外观、菜单及深层流程的 MN5 复刻；随后要求 px 级布局也一致。本文取代“路线完成后即整体一致”的旧口径。
>
> 状态只能标：`已实现且有证据` / `部分实现` / `未实现` / `未验收`。`npm run verify` 全绿只证明已覆盖的合成断言，不证明 MN5 全量一致。

## 1. 完成定义

“全量复刻完成”必须同时满足：

1. **功能**：每个 MN5 用户可用功能都有对应实现，或有明确的宿主等价行为；不能只做菜单占位。
2. **表面**：主页、工作区、阅读器、脑图、大纲、看板、复习、AI、搜索、导入导出、设置、模板、弹窗、右键/长按菜单、错误与空态均覆盖。
3. **菜单**：顶部胶囊、节点菜单、上下文菜单、原生菜单栏逐项核对标签、顺序、图标、分组、勾选、启用态和实际动作。
4. **外观**：同对象、同状态、同窗口、同缩放比较；浅色/深色、三视口、窄窗、桌面/Pad，主要锚点 ≤4 CSS px；不仅检查几何和性能。
5. **深层行为**：对象身份、引用/克隆、持久化、撤销/重做、冲突、媒体、页码与坐标、导入导出、失败回滚、离线和错误路径与 MN5 契约一致。
6. **真实流程**：云盘、文件导入导出、网页、OCR、AI、原生浮窗、真笔/触摸等必须实际闭环；合成测试不能替代这些验收。
7. **证据**：每项有实现、自动断言和对应实机证据；未测、不可达和平台差异必须显式登记，不能报“全量完成”。

## 4. 云盘（百度优先，夸克备选）

### 官方能力依据

百度网盘开放平台公开提供：

- OAuth 2.0 授权码/设备码与刷新令牌；
- `GET https://pan.baidu.com/rest/2.0/xpan/file?method=list`：目录列表、分页、排序；
- 文件信息与 `dlink` 下载，要求 `User-Agent: pan.baidu.com`，保留完整签名 URL 与 `access_token`；
- 上传预创建、分片上传与创建文件接口；
- 第三方应用通常只能访问 `/apps/<应用名>/` 授权目录，不能默认读取整个网盘。

官方资料：`https://pan.baidu.com/union/doc/`（授权介绍、接入流程、文件列表、下载、SDK）。夸克公开文档不足，暂不作为首条实现路径；不使用网页 Cookie、密码或逆向 API。

### 必做功能与验收

1. 应用配置与授权：AppKey/Secret 不进源码和日志；授权码或设备码；state 防 CSRF；token 安全存储、刷新、撤销、重新授权。
2. 目录浏览：根目录与子目录、分页、排序、文件类型/大小/时间、返回路径、加载/空/错误态。
3. 下载导入：选择单/多文件 → 临时文件 → 格式校验 → 同名冲突策略 → 加入当前或指定学习集 → 源记录保存云盘身份；取消和失败不产生半成品成员。
4. 上传：学习集 ZIP/文档上传到授权目录；大小文件与分片；同名策略；断网、令牌过期、限流和重试；不得静默覆盖。
5. 安全：日志和导出文件不记录 token/dlink；不在未经用户动作时上传学习资料；不上传密码；不绕过授权目录。
6. 验收：真实账号浏览、下载导入、上传回读、token 刷新、撤销授权、断网/404/冲突、大文件分片、重开恢复。合成 mock 只能覆盖协议与状态机，不能替代真实授权闭环。

外部前置：需要百度开发者应用的 AppKey/Secret、授权目录和回调配置。**用户有网盘账号不等于已经有开发者应用权限**；届时由用户完成一次官方授权，不提供账号密码。

## 6. 实施顺序（按依赖，不再按路线删减）

1. **基线冻结**：把每个菜单、表面、手势、设置、数据格式与真实流程补成可执行断言；未知项标 `待取证`。
2. **可见新功能优先（5.0.2）**：先冻结 5.0.2 实机基线，再做简洁显示、书脊滚动/封面搜索、首次摘录提示定位；云盘真实授权待验。
3. **文档深层与同步中心**：PDF 合并、目录键盘矩阵、等待上传/双端缺失状态。
4. **默认值与修复**：首次摘录/遮挡默认值、手写解绑/切橡皮、文本框字号与把手、长卡截图、重复 ID。
5. **快捷键与真机**：5.0.2 快捷键、Sidecar/数位笔、真笔/掌触。
6. **全表面外观与性能**：所有场景/主题/视口/弹窗/菜单的同态对照、大学习集响应、购买权益的合法能力评估。
7. **最终冻结**：5.0.2 全量回归 + 独立复建 + 新交付包；旧 1.4.0 仅为 5.0.0 阶段构建。
