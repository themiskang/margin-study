# 已知限制

本文件记录当前版本已知但未修复的问题，便于使用者评估影响。每条都注明影响范围与触发条件。

## 用户可见

1. **跳页后立即开目录栏，页码可能回退到第 1 页**
   - 触发：跳转到某页后**立刻**点击「文档目录与书签」。
   - 影响：随后的「插入目录」记录页码错误；**不丢数据、不改批注**。
   - 原因：平滑跳转只有 1.2 秒硬窗口，重排打断后页码被滚动观察器覆盖。
   - 状态：非阻断，计划后续版本修复。

## 呈现与环境

2. **参考层透明度依赖主题变量**：社区主题若覆盖 `--ms-ink-reference-opacity`，参考层透明度以主题为准；未定义时回退 0.35。
3. **原生菜单渲染**：真实 Obsidian 的原生菜单不在网页层渲染，自动检查只能验证菜单内容与顺序；视觉呈现需实机确认。
4. **平板手写手感**：420 毫秒长按阈值、掌触防误触、触控拖拽等属真机体验，未纳入自动检查。

## 测试通道

5. **两套浏览器后端的少量口径差异**：有窗口的测试通道在窗口被遮挡时动画帧会变慢，导致少数界面用例差异（缩放纵向 60 像素、深色纸面刷新时机、侧栏关闭后段落位置）。这些差异**不影响插件本身**，只影响该通道下的检查结果。
