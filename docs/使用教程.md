# MarginStudy 全功能使用手册

> 面向日常使用者的完整操作参考。需要查某一项功能、按钮、设置或快捷键时，可直接按目录检索。
>
> **术语白话速查**（首次遇到时对照）：
> - **资料库（Vault）**：Obsidian 中用来存放笔记和学习文档的资料库。
> - **学习集**：把同一主题的多篇文档、卡片、脑图和复习进度收在一起的项目空间。
> - **FSRS**：一种按遗忘曲线安排下次复习时间的算法（本插件使用 `ts-fsrs/FSRS-6`）。
> - **挖空（Cloze）**：把卡片里的关键词藏起来（如 `{{答案}}` 或 `{{c1::答案}}`），复习时先回忆再揭开。
> - **侧车文件（`.mstudy.json`）**：和原文档放在同一个文件夹里的批注记录文件，不会改动原 PDF。

## 1. 快速上手

从安装到完成第一次阅读 → 摘录 → 成卡 → 入脑图 → 复习闭环，只需 6 步：

### 第 1 步：安装并启用插件
1. 确认 Obsidian 版本为 1.4.0 及以上。
2. 在资料库默认配置目录 `.obsidian/plugins/margin-study/`（如自定义了 Obsidian 配置目录则放入对应目录下的 `plugins/margin-study/`）中，放入 `main.js`、`manifest.json`、`styles.css`、`pdf.worker.js`（macOS 如需本地扫描页识别，另放入 `ocr.swift`）。
3. 在 Obsidian 设置中启用第三方插件并打开 MarginStudy（重启方式及安全模式/第三方插件菜单名称因 Obsidian 版本而异）。
4. 启用后，Obsidian 左侧功能区会出现书本图标（「MarginStudy 学习工作区」）。

### 第 2 步：打开学习工作区
- 点左侧书本图标，或打开 Obsidian 命令面板（宿主默认 `Cmd/Ctrl + P`）执行「打开 MarginStudy 学习工作区」（命令 ID：`open-study-workspace`）。
- 首次启动插件或无活动受支持文档时进入会展示学习集主页；点「新建」，输入名称后点「创建学习集」，或直接点已有学习集进入工作区（若点击书本图标时当前已有打开的受支持文档，会直接在工作区中打开该文档）。

### 第 3 步：打开一篇 PDF
- 从 Obsidian 左侧文件列表打开 PDF（默认开启「用 MarginStudy 替代原生阅读器」），或右键文件点「在 MarginStudy 中打开」。
- 也可在工作区顶部点「文档」胶囊 → 「从资料库…」或「从文件」导入。
- 桌面宽窗口下工作区默认左右分栏：左侧为「文档阅读区」，右侧为「脑图区」（当窗口宽 701–900 px 且高不少于 650 px、文档为默认左侧摆放、学习集侧栏与右侧辅助栏均收起且文档与脑图均显示时，会自动转为上下排布）。

### 第 4 步：选中文字并高亮
1. 在 PDF 正文中用鼠标或手指拖选文字即可弹出操作菜单手动高亮（单击式微拖小于 6 CSS px 会收起弹窗，宽、高均小于 6 CSS px 的极小选区会被拒绝）；4 个中文字符（英文按 2 倍折算为 8 个有效字符）的门槛只限制普通自动摘录与自动成卡，不限制手动高亮与「连续摘录」。
2. 松手后选区附近会弹出操作菜单（默认优先放在选区下方，下方空间不足时尝试放到上方），点「高亮」（或直接点任意颜色圆点，或点「下划线」「删除线」「批注」）。

### 第 5 步：自动生成卡片并进入脑图
- 插件默认开启「高亮后自动成卡」与「生成卡片自动进脑图」。
- 满足默认自动成卡条件且学习集摘录去向未设为「只留在文档」时，高亮完成后右侧「脑图区」会自动出现对应的卡片节点；在「文档与脑图联动设置」处于双向（「Two-way Sync」）或脑图到文档（「Mind Map → Doc」）模式时，点击该节点左侧 PDF 会跳回原页并闪烁定位（仅开文档到脑图「Doc → Mind Map」时点击节点不会回源）。
- 如果你关闭了自动成卡，可点击已高亮的文字，在浮条里手动点「摘录卡」「评论卡」或「闪卡」。

### 第 6 步：加入卡组并开始复习
1. 在工作区底部切到「回忆」场景点「复习」打开右侧复习辅助栏：若尚未绑定卡组，先点「＋ 添加复习卡组」或「选择复习卡组」；已绑定卡组时先点「浏览复习卡组」，卡组内有到期题时点「进入问答评分」（无到期题时该按钮禁用）。也可在命令面板执行「开始复习（到期的卡）」（命令 ID：`start-review`），有到期卡时通常先进入卡组浏览，再点「进入问答评分」开始评分。
2. 如果尚未建卡组，弹窗会引导你输入名称并点「新建卡组」、绑定到学习集并点「使用此卡组」，之后再到卡片详情或卡片列表点「加入复习」（或在脑图卡片菜单点「添加到复习」）。
3. 进入问答评分界面后先展示题目，心里回忆答案后点「显示答案」（或按 `Space`）。
4. 按记忆程度点底部四个按钮之一：「重复」「难」「良好」「易」（或按键盘 `1`–`4`），算法会自动安排下次复习时间。

## 2. 界面总览

MarginStudy 学习工作区支持**两种界面模式**，选中学习集后可随时切换，学习数据完全互通。

### 2.1 场景模式 vs 传统界面

| 对比项 | 场景界面（默认） | 传统界面 |
| --- | --- | --- |
| 顶部结构 | 简洁的四胶囊信息条 + 「跟着选中」 + 摘录落点按钮 | 完整工具按钮条（含学习集侧栏、撤销/重做、脑图开关、手写/摘录工具、专注、对照、搜索、目录等） |
| 底部工具栏 | 按当前场景模板展示对应工具（如「摘录」「手写」「整理」「回忆」或「阅读」「书写」「回忆」） | 固定三模式胶囊：「阅读」「书写」「回忆」 |
| 切换方式 | 顶部「场景模板」胶囊 → 「切换到传统界面」；或快捷键 `Cmd/Ctrl + Alt + I` | 顶部「场景模板」胶囊 → 「切换到场景界面」；或快捷键 `Cmd/Ctrl + Alt + I` |
| 命令面板 | 「切换界面模式」（`toggle-interface-mode`） | 「切换界面模式」（`toggle-interface-mode`） |

### 2.2 顶部四胶囊与快捷按钮

无论哪种模式，工作区顶部左侧都有一条「当前工作区信息」胶囊栏：

| 入口 | 作用 |
| --- | --- |
| 房子图标（「打开学习集与文档」） | 打开学习集主页（包含「学习集」「复习卡组」「资料库」「版本库」「设置」） |
| 「学习集」胶囊 | 切换、置顶、分类、新建或管理当前学习集（搜索框在学习集主页中提供） |
| 「场景模板」胶囊 | 切换系统/自定义场景模板、「摆放界面」「更多场景模板…」「编辑场景模板…」、切换场景/传统界面 |
| 「文档」胶囊 | 切换本学习集文档、单/双/三视图对照、导入文档、翻页模式、裁边、编辑 PDF 页面、导出文档等 |
| 「脑图」胶囊 | 切换/「管理脑图」、打开「大纲」「卡片分组看板」「导出思维导图」「导出学习集」「朗读卡片」 |
| 星星图标（「收藏」） | 常用功能快捷菜单，点「编辑收藏…」可勾选要显示的功能（按固定索引顺序排列） |
| 放大镜图标（「全局搜索」） | 打开跨脑图、文档目录、文档正文、功能的全局搜索面板 |
| 「跟着选中」与摘录落点按钮（场景界面） | 设置新摘录默认去向与脑图落点（详见第 10 节） |

### 2.3 底部工具栏与简洁显示

- **展开/收合**：点底部工具栏最左侧的收合按钮（「收合底部工具栏」/「展开底部工具栏」），可将底部栏收合为短条按钮。
- **简洁显示**：
  - 进入方式：按住工作区顶部左上角的「简洁显示把手」约半秒（源码为 420ms，见 `src/workspace/studyWorkspace.ts`；进入简洁显示后把手会移到顶部居中），或按快捷键 `Cmd/Ctrl + Alt + H`（命令 ID：`toggle-clean-view`）。
  - 效果：隐藏四周工具栏与浮窗。如果你正在使用手写工具（笔、荧光笔、铅笔、橡皮、套索），会自动保留一条「精简笔条」（「笔」「荧光」「铅笔」「橡皮」）。
  - 退出方式：轻点顶部把手（「恢复全部按钮」）或按 `Esc`。

### 2.4 右侧辅助面板（卡片 / 脑图 / 大纲 / 复习 / 研究 / AI）

- **脑图区**：默认在工作区右侧。拖动中间分隔条（「调整文档与脑图比例」）可调节文档与脑图宽窄；在传统界面可点「脑图」按钮显隐，或在「学习集更多设置」里点「显示/隐藏脑图」。
- **卡片与复习等辅助栏**：通过「学习集更多设置」（传统界面右上角 `…` 图标，场景界面经「文档 - 更多」内的学习集更多设置入口）或场景工具打开，支持切换：
  - 「卡片」：工作区辅助栏展示「卡片分组看板」（独立右侧边栏另提供「分组看板」与「卡片列表」切换）。
  - 「复习」：当前学习集绑定的复习卡组面板。
  - 「研究」：内置「研究浏览器」。
  - 「AI」：「AI 学习助手」侧栏。
- **大纲**：在顶部「脑图」胶囊 → 「大纲」打开，或在命令面板运行「打开 MarginStudy 侧边栏」（`open-sidebar`）查看大纲与脑图页签。
- **文档位置**：通过 顶部「场景模板」胶囊 → 「摆放界面」（或「学习集更多设置」→ 「工作区设置…」），可将文档放在「文档置于左侧」「文档置于右侧」「文档置于底部」。

### 2.5 学习集侧栏与文档标签

- **学习集侧栏**：显示当前学习集的全部文档并支持「查找文档」。在传统界面点顶部左上角「显示或隐藏学习集列表」，或在场景界面点底部「更多」→ 「显示/隐藏学习集侧栏」开关。
- **文档标签栏**：在工作区阅读区顶部显示已打开的文档标签，可拖动排序；在「文档 - 更多」里点「Show Document Tabs」，或在「工作区设置…」点「显示文档标签」/「隐藏文档标签」、「管理文档标签与数量」（默认最多显示 7 个，可调范围 1–30）。

## 3. 打开文档

### 3.1 支持的文件格式

按源码 `src/documents/formats.ts`，MarginStudy 支持以下 7 种扩展名：

| 格式类型 | 扩展名 | 说明 |
| --- | --- | --- |
| PDF 文档 | `.pdf` | 完整支持高亮、区域摘录、手写分层、裁边、页编辑、留白、OCR 扫描识别、双页等 |
| 书页重组文档 | `.msref` | 插件生成的跨文档重组/合并引用文档，使用 PDF 阅读器打开 |
| Word 文档 | `.docx` | 支持文字高亮、批注、摘录卡、手写、语音批注与朗读 |
| 电子书 | `.epub` | 静态阅读、目录导航、高亮、批注与朗读 |
| 网页文档 | `.html` / `.htm` | 支持本地 HTML 与导入的网页/微信文章，可高亮、批注与成卡 |
| Markdown 笔记 | `.md` | 不自动接管（保持 Obsidian 原有编辑体验），可通过右键或命令在 MarginStudy 中打开阅读与批注 |

### 3.2 三种打开方式

1. **从文件列表直接打开**（PDF / Word / EPUB / HTML）：
   - 需开启 设置 → MarginStudy → 「用 MarginStudy 替代原生阅读器」（默认开启）。
   - 关闭该开关后，新打开的文件会恢复使用 Obsidian 原生查看器。
2. **文件右键菜单**：
   - 在 Obsidian 文件列表右键任意受支持的文档（含 Markdown），点「在 MarginStudy 中打开」。
3. **在学习工作区内打开或导入**：
   - 顶部「文档」胶囊 → 从当前学习集列表点击切换；或点「从资料库…」「从文件」「新建笔记本」「从Web」「从百度网盘」「添加外部源」。
   - 也可把电脑里的文件拖拽到阅读区窗口，在弹出的同名处理确认中选择导入策略后打开。

### 3.3 相关命令（打开命令面板）

| 命令名称 | 命令 ID | 作用 |
| --- | --- | --- |
| 「打开 MarginStudy 学习工作区」 | `open-study-workspace` | 打开学习工作区 |
| 「在 MarginStudy 中打开当前文档（PDF / Word / EPUB / HTML / Markdown）」 | `open-document-reader` | 按文件类型自动选择阅读器打开当前标签页文档 |
| 「在 MarginStudy 中打开当前 PDF」 | `open-reader` | 用 MarginStudy PDF 阅读器打开当前 PDF |
| 「在 MarginStudy 中打开当前 Word 文档」 | `open-word-reader` | 用 MarginStudy Word 阅读器打开当前 `.docx` |
| 「打开 MarginStudy 侧边栏」 | `open-sidebar` | 打开右侧边栏（大纲/脑图） |
| 「打开 MarginStudy 思维导图」 | `open-mindmap` | 在右侧打开独立脑图视图 |

## 4. 阅读器全功能

### 4.1 翻页、跳转与阅读历史

| 功能 | 操作入口 | 说明 |
| --- | --- | --- |
| 上一页 / 下一页 | 阅读器工具栏「上一页」「下一页」，或键盘 `←` / `PageUp`、`→` / `PageDown` | 逐页或逐组翻页 |
| 首页 / 末页 | 键盘 `Home` / `End` | 跳到第一页或最后一页 |
| 跳转到指定页码 | 顶部「文档」胶囊或底部「更多」→ 「转到指定页码」；或直接修改独立阅读器工具栏的页码输入框 | 输入页码按回车直达 |
| 返回 / 前进阅读位置 | 底部「更多」→ 「返回」/「前进」；或独立阅读器工具栏「返回上次阅读位置」「前进到下一阅读位置」 | 从目录、脑图跳转后可一键回到原位 |
| 翻页方式切换 | 顶部「文档」胶囊 → 「竖向阅读」/「翻页阅读」；或「文档 - 更多」→ 「阅读设置」→ 「文档翻页方式」（「横向翻页」/「纵向滚动」） | 支持连续滚动与逐组翻页 |

### 4.2 缩放与双指捏合

- **缩放范围**：30%–400%（源码限制 `0.3`–`4`，见 `src/pdf/readerView.ts`）。
- **桌面端**：点独立阅读器工具栏的「缩小」（`−`）、「放大」（`+`）或「适应宽度」。
- **触屏 / 平板**：在 PDF 页面上直接**双指捏合缩放**；手写、荧光笔、橡皮、套索状态下都可直接双指缩放，无需先切回手形工具。
- **缩放重绘**：捏合缩放过程中先显示几何预览，松手后按新比例重绘当前页。
- **默认缩放与页间距**：在 设置 → MarginStudy → 阅读 → 「默认缩放」（0.5–3.0，默认 1.4）和「页间距 (px)」（默认 24）中调整。

### 4.3 双页模式与对照阅读

- **双页模式 (PDF)**：顶部「文档」胶囊 → 先切到「翻页阅读」，再点「双页模式 (PDF)」（竖向连续滚动时不可直接开双页，菜单会提示「双页模式 (PDF)（请先切回翻页阅读）」）。独立阅读器工具栏的「页面布局」下拉框也可切换「单页」/「双页」。
- **多文档对照**：顶部「文档」胶囊支持：
  - 和《文档名》对照（按实际文档名显示）：把另一篇学习集文档并排打开，支持勾选「同步滚动」。
  - 「单视图」「双视图」「三视图」：最多同时对照 3 篇文档。
  - 「自动方向」「左右排列」「上下排列」：控制对照排布方向。
  - 「交换两篇文档的位置」与「结束对照，保留此文档」。

### 4.4 目录、缩略图、书签、标注与卡片五合一导航

点工作区「文档」胶囊 → 「文档与目录」，或底部「更多」（「文档 - 更多」）顶部五个图标，可打开左侧「书页查找」导航面板，包含五个标签页：

1. **「目录」**：查看 PDF 内嵌目录或用户编辑的目录，点击直达对应页；支持在「文档」胶囊点「AI 拆书」用 AI 生成目录。
2. **「缩略图」**：按页浏览页面缩略图，顶部「文档书脊」显示当前页码与阅读进度条。
3. **「书签」**：列出当前文档已收藏的书签页；在「文档 - 更多」点「添加书签」/「删除书签」管理当前页书签，独立阅读器工具栏有「上一书签」「下一书签」。
4. **「标注」**：列出当前文档笔记本内的自由批注（文本框/图片框）与有笔迹的手写记录（不含普通高亮、下划线与正文批注），点击定位原文。
5. **「卡片」**：列出来源于当前文档、属于当前文档笔记本且未隐藏的卡片，点击跳转回原文。

### 4.5 搜索页内文字

- **打开方式**：在工作区按 `Cmd/Ctrl + F`，或在命令面板运行「在 PDF 中搜索（Ctrl+F）」（命令 ID：`pdf-search`）；场景界面可在「文档 - 更多」点「文档内搜索」，传统界面可直接点顶部工具条的「文档内搜索」。
- **操作**：在「搜索本文档…」输入框键入关键词，按 `Enter` 跳「下一处」，按 `Shift + Enter` 跳「上一处」，按 `Esc` 或点关闭按钮退出。

### 4.6 阅读外观、裁边、页编辑、折叠页与朗读

- **阅读主题**：在「阅读」场景点「主题」循环切换，或在「文档 - 更多」→ 「阅读设置」→ 「主题」选择（五种阅读主题：`white` / `sepia` / `gray` / `dark` / `green`，仅影响学习工作区阅读面，不改 Obsidian 宿主主题）。
- **空白底与手写置顶**：在「文档 - 更多」中可勾选「Blank Background」（隐藏 PDF 底图，仅看手写与批注）与「Handwriting on Top」（手写笔迹浮在正文上方）。
- **裁边**：顶部「文档」胶囊或「文档 - 更多」→ 「裁边」，拖动四周红手柄可内裁去白边或向外扩页；按「完成」保存，`Esc` 取消，不改写原 PDF 文件。
- **编辑 PDF 页面**：顶部「文档」胶囊或「文档 - 更多」→ 「编辑PDF页面」，支持插入空白页、旋转、移动、删除页面，之后可用「导出编辑后的 PDF」（`export-edited-pdf`）导出新文件。
- **扫描页文字识别（OCR）**：场景界面在「文档 - 更多」→ 「识别当前扫描页」，传统界面在顶部工具条点「识别当前扫描页」（仅 macOS，需本机已配置识别组件且在「文档」胶囊 → 「PDF OCR设置」开启「Apple OCR Engine」）。
- **朗读与音视频**：在「文档 - 更多」中可使用「朗读控制」（支持 0.5×–2.5× 调速、暂停/继续、停止）、「录制语音批注」和「Audio & Video」（添加音视频批注）。

## 5. 选中与高亮

### 5.1 拖选文字与弹出操作菜单

在「摘录」或「书写」场景选择「文本」工具后，拖动选中一段文字，松手会弹出选区菜单。默认主菜单包含核心操作，其余项收纳在更多展开区，且可按场景模板自定义显示哪些按钮：

| 按钮 | 作用 |
| --- | --- |
| 「高亮」 | 用当前默认颜色高亮选中文字 |
| 「摘录卡」 | 高亮并**强制**生成一张摘录卡（即使关闭了自动成卡开关） |
| 「复制」 | 将选中文字复制到系统剪贴板 |
| 「下划线」「删除线」「批注」 | 添加对应样式标注或文字批注 |
| 颜色圆点（「摘录颜色 」+ 色值） | 直接用前 4 个快捷色之一生成高亮 |
| 「向 AI 提问」 | 把选中文字作为上下文送到「AI 学习助手」 |
| 「研究」 | 把选中文字送到「研究浏览器」检索 |
| 「翻译」 | （PDF 支持页编辑、已绑定自定义 AI 且选区不超过 20,000 字符时）将选中文字翻译并作为页内译文插入当前页，双击可编辑 |
| 「朗读」 | 朗读当前选中文字 |
| 「识别选区并高亮」 | 当开启 `Selection Correction`（OCR 选区纠偏）时出现；开启「Apple OCR Engine」且识别有结果时按识别文本高亮，否则按原文高亮 |

点击页面上**已有**的高亮/下划线/批注，会弹出操作条：可手动转为「摘录卡」「评论卡」「闪卡」，切换「切换整卡遮挡」或「删除」；若该标注本身是文字批注或已有备注，另提供「编辑批注」/「加批注」；若对应卡片在当前脑图已有节点，另提供「撤出脑图」。

### 5.2 拖选文本自动高亮开关

- **路径**：设置 → MarginStudy → 阅读 → 「拖选文本自动高亮」（或在「阅读设置」→「更多设置」→「Excerpt」→「拖选文本自动高亮」）。
- **默认值**：关闭（拖选松手只选中并弹出操作菜单）。
- **开启后**：在「摘录」或「书写」场景下，拖选文字松手后会自动按当前颜色生成高亮（受「自动摘录与成卡最短字数」限制，默认中文 4 字、英文 8 字符，填 0 关闭字数门槛）。

### 5.3 连续摘录

适合一边通读一边把同一知识点的多段零散文字收到**同一张卡片**里：
1. 先打开一篇 PDF，并在「摘录」或「书写」场景底部把工具切到「文本」或「矩形」（否则「连续摘录」按钮处于禁用状态；直接拖选文字需使用「文本」工具），再点「连续摘录」（Mac 快捷键 `Cmd + Alt + K`）。
2. 底部出现状态条（显示 `连续摘录中 · ` 加当前段数）。
3. 连续拖选多段文字（不受「拖选文本自动高亮」开关限制，始终逐笔自动摘录），它们会依次追加到同一张摘录卡中。
4. 完成后点状态条上的「完成」按钮结束本次连续摘录。

### 5.4 多选（块选择）与跨页选择

- **块选择**：在「阅读」或「摘录」场景底部点「块选择」，可在文档中按段落块快速点选，适合整段摘录；按 `Esc` 退出块选择。
- **跨页选择**：PDF 支持从上一页末尾拖选到下一页开头，坐标按页分别记录（`pdfGeometry`），高亮会按页覆盖跨页区间；从卡片回源定位时只跳转到第一个有效页并闪烁标注（单页布局下需手动翻页查看后续页）。

## 6. 区域摘录

适合图表、公式、扫描版 PDF 等无法直接拖选文字的内容。

### 6.1 矩形框选区域摘录（与手写套索的区别）

| 工具名 | 所在位置 | 作用 |
| --- | --- | --- |
| 「矩形」（区域摘录） | 「摘录」/「书写」场景底部工具栏，或传统界面顶部「区域摘录」 | 在页面上**拖拽矩形框**截图，生成区域摘录标注 |
| 「套索」（手写套索） | 「摘录」/「手写」/「书写」场景底部工具栏 | 圈选**已有手写笔迹**进行移动、改色、复制、删除或「转摘录」 |

### 6.2 区域成卡与区域转图片

1. 先打开 PDF，点「矩形」进入区域摘录模式（提示「区域摘录模式：在页面上拖拽框选区域，松开后生成摘录」）。
2. 在**已渲染的 PDF 页面**上按住拖拽框出目标区域并松手；框选区域宽、高需各至少 `20px`（公式等过小的区域可能没有反应，不会生成摘录），达到尺寸要求后插件会自动截取该区域图片。
3. **自动成卡**：默认开启 设置 → MarginStudy → 阅读 → 「区域摘录自动成卡」，单次区域摘录在满足上述页面与尺寸条件时松手即生成一张带截图的摘录卡（是否同步出现在右侧脑图以学习集「摘录去向」为准：选「自动加入脑图」总会建节点，选「只留在文档」不会建节点，选「后续摘录 · 跟随默认」时按全局「生成卡片自动进脑图」开关决定）；若当前开启了矩形「连续摘录」且已有目标卡，再次框选合格区域会向该卡追加来源与图片，而不会新建卡片。
4. **手动操作**：如果关闭了自动成卡，点击页面上的区域框，在浮条里点「摘录卡」「评论卡」「闪卡」或「加入脑图」（注意：当学习集摘录去向设为「只留在文档」时，点「加入脑图」只会创建/保留卡片，不会在脑图新建节点）。
5. **查看图片与遮挡**：在卡片详情中，区域截图显示在「来源图片（点击放大）」下，点击可灯箱全屏查看；有图片的卡片可点「创建 / 编辑图片遮挡」制作图片遮挡复习题。

### 6.3 留白（页边扩展与空白书写区）

在 PDF 中可在正文旁或页间插入留白区做深度笔记，不破坏原 PDF：

- **入口 1（底部工具栏）**：在「摘录」或「书写」场景点「留白」进入留白添加模式。
- **入口 2（独立阅读器顶部 / 「文档 - 更多」）**：点「留白 / 页边设置」或在「文档 - 更多」找到「留白」分组，包含三种留白显示模式（**「Normal」**常规展开、**「Margin」**页边模式、**「Collapse」**折叠收起）与**「Margin Comment Area」**（开关页边批注区）；独立阅读器的「留白 / 页边设置」浮窗中另提供**「添加留白」**按钮，可在页面指定位置插入可写文字、手写、贴图的留白区域（工作区请用底部工具栏的「留白」按钮添加）。

## 7. 手写与批注

### 7.1 画笔、橡皮与手写套索

在「手写」或「书写」场景的底部工具栏（或传统界面顶部「手写画笔与设置」）可切换以下工具：

- **内置 4 支默认笔刷预设**（来源 `src/types.ts` 的 `DEFAULT_HANDWRITING_PRESETS`）：
  - 「原子笔 1」（`ballpoint`，黑色 `#000000`，默认粗细 `3.4`）
  - 「墨水笔 1」（`fountain`，黑色 `#000000`，默认粗细 `2.6`）
  - 「荧光笔 1」（`highlighter`，黄色 `#ffd54f`，默认粗细 `21`，透明度 `0.8`）
  - 「铅笔 1」（`pencil`，灰色 `#696969`，默认粗细 `1.8`，透明度 `0.85`）
- **工具栏按钮**：
  - 画笔按钮与设置入口（按工具栏区分）：
    - **「手写」场景**：底部提供「普通笔 1」「普通笔 2」「荧光笔」「铅笔」（均仅支持点击切换），点「手写层」可直接打开「文档手写设置」调整颜色、粗细（普通笔 0.5–24，荧光笔 0.5–64）、透明度或复制/删除预设。
    - **「书写」场景**：底部提供「普通笔 1」「普通笔 2」「荧光笔」（均仅支持点击切换，无单独「铅笔」按钮），点「更多」打开「手写预设列表」后可选用铅笔预设，或点「手写设置…」进入编辑。
    - **传统界面**：底部「书写」工具栏的「普通笔 1」「普通笔 2」「荧光笔」支持**长按**约 0.65 秒（源码 650ms）直接打开「文档手写设置」，顶部「手写画笔与设置」支持**双击**打开。
  - 「橡皮」/「橡皮擦」：划过笔画松手即**整笔删除**，误删可撤销。
  - 「套索」：圈住一组笔迹后，按住选框拖动可**移动**；上方浮出「套索工具」条，包含：「颜色」「剪切」「复制」「AI 转文本」「删除」；扩展条包含：「转摘录」「解除绑定」。
  - 「手形」/「手形工具」：退出手写，恢复正常滚动与点选。
- **手写层（分层整理）**：在「手写」场景点「手写层」（或独立阅读器点「图层」），打开「文档手写设置」，可新建、重命名、合并、删除手写图层，只有当前图层可编辑，另一图层可设为参考叠加层；也可在此开关「消失笔」（笔迹约 4 秒后消失，不会保存）。
- **手写同步与防误触**：触控笔支持压感；落笔期间及抬笔后约 1.2 秒内（源码 `PEN_COOLDOWN_MS = 1200`）自动过滤手掌触碰。

### 7.2 撤销与重做

- 点底部工具栏或传统界面顶部的「撤销」「重做」，或按快捷键 `Cmd/Ctrl + Z` / `Cmd/Ctrl + Shift + Z`。
- 支持手写落笔、橡皮删除、套索移动/删除、自由批注、摘录等操作的撤销与重做。

### 7.3 手写转文字（「AI 转文本」）

1. 点「套索」圈住想要识别的手写笔迹。
2. 在套索浮条中点「AI 转文本」。
3. 弹窗会调用已绑定的自定义 AI 服务识别选中笔迹中的文字（需先在 AI 面板完成自定义 AI 绑定，见第 13 节）。
4. 识别完成后可在文本框中校对，点「复制文字」使用。

### 7.4 自由批注（文本框与图片框）：移动、缩放、旋转、裁剪与删除

在「手写」场景点「文本框」/「图片框」（场景界面亦可在「文档 - 更多」点「文字批注」/「插入图片批注」，传统界面在顶部工具条点「文字批注」/「插入图片批注」），在页面上点击放置自由批注。选中批注后顶部出现控制条：

| 控件 | 图标 / 名称 | 作用 |
| --- | --- | --- |
| 移动 | `⠿`（「移动批注」） | 按住拖动批注在页面中的位置 |
| 编辑 / 替换 | `✎`（「编辑文字批注」/「替换图片批注」） | 双击或点击进入页内富文本编辑（支持字体、字号、`Cmd/Ctrl + B/I/U` 加粗/斜体/下划线、前景与背景色，`Cmd/Ctrl + Enter` 完成编辑）；图片批注则替换图片 |
| 缩放 | `◢`（「缩放批注」） | 按住右下角拖拽改变批注框大小 |
| 旋转角度 | 数字框（「旋转批注角度」） | 输入 `-360` 到 `360` 之间的整数度数，精确旋转批注角度 |
| 裁剪 | 「裁剪」（仅图片批注） | 对插入的图片批注做非破坏性裁剪 |
| 生成卡片 | `◇`（「由自由批注生成卡片」） | 把当前自由批注生成为一张卡片 |
| 删除 | `×`（「删除自由批注」） | 删除该自由批注 |

## 8. 卡片

### 8.1 卡片类型与入口

按源码 `src/cards/cardView.ts`，卡片共有三种基础类型，加入复习卡组后在详情顶部显示为「复习卡」：

- **「摘录卡」**（`excerpt`）：来自文档高亮、区域摘录或手写转摘录。
- **「评论卡」**（`comment`）：以个人批注和思考为主的卡片。
- **「闪卡」**（`flashcard`）：专门用于问答与填空复习的卡片，详情页额外提供「填空卡模板」（「文本挖空」「独立填空」「两个独立填空」「选择」「判断」）。

打开卡片管理的入口：命令面板运行「打开卡片管理」（`open-cards`），或在工作区点「学习集更多设置」→ 「卡片」。

### 8.2 卡片字段与编辑

在卡片列表或卡片管理中点击卡片可打开「卡片详情」（在工作区脑图中单击节点默认只选择并回源，双击节点打开编辑），可编辑以下字段：

| 字段 / 按钮 | 说明 |
| --- | --- |
| 「标题」 | 卡片标题，也会作为脑图节点的显示标题 |
| 「正面 / 摘录（Markdown）」 | 支持 Markdown 语法与即时预览；选中已保存文字后点「挖空/取消挖空」可快速加/去挖空 |
| 「来源图片（点击放大）」 | 区域摘录截图，点击灯箱放大；有图时底部出现「创建 / 编辑图片遮挡」按钮 |
| 「答案（Markdown，留空时使用摘录内容）」 | 闪卡答案或个人笔记，同样支持 Markdown 与「挖空/取消挖空」 |
| 「标签（逗号分隔）」 | 多个标签用英文逗号分隔；标签配色可在 设置 → MarginStudy → 「标签配色」定制 |
| 「颜色」 | 16 色色板（卡片颜色 1–16）及「清除」按钮，方便在卡片盒与看板中按颜色筛选 |
| 「关键词（触发解释卡，逗号分隔）」 | 填写后生成蓝色关键词标签，点击可在已打开的独立 PDF/Word 阅读标签页中按卡片来源搜索定位（仅打开工作区内嵌阅读器或 HTML/EPUB 时不可直接定位） |
| 「关联卡片」 | 建立与其他卡片的双向/单向关联，底部列出已关联卡片并可点击 `×` 断开 |
| 「复习副本内容」/「复制为复习卡」 | 勾选标题/正文/笔记/图片及指定遮挡，创建独立复习副本；副本页提供「从来源刷新内容」 |
| 「朗读」/「停止朗读」 | 朗读当前卡片的标题、正面与答案 |

修改标题、正面、答案、标签、关键词等常规字段后请点「保存」落盘（颜色修改/清除及保存后的「挖空/取消挖空」会立即写入）。

### 8.3 来源定位、合并与重复检测

- **来源定位**：在卡片详情点「跳转原文」（或在多段摘录块旁点「定位原文」），自动打开源文档并闪烁定位到原批注位置。
- **合并卡片**：在脑图中开启多选并选中 2 张及以上卡片，点「合并」（或单选时在菜单点「合并到」选择目标卡片）。合并后原卡片会作为组员保留在合并记录中，节点上显示 `•••` 标记。
- **解除合并**：在合并后的卡片详情点「解除合并」（或在脑图更多操作点「解除合并」），可恢复合并前各张卡片的内容、来源和各自复习状态。
- **检测重复卡片**：命令面板运行「检测重复卡片」（`dedup-cards`），按规范化后的卡片正面文本精确分组（忽略大小写与空白；编号挖空 `{{c1::答案}}` 会去掉标记并与纯文本同组，普通挖空 `{{答案}}` 只去掉结尾 `}}` 而保留开头 `{{`，因此与纯文本不会分到同组），找出同组卡片并支持一键「合并到此」。

### 8.4 FSRS 复习参数与暂停/移出复习

- **FSRS 参数**：每张卡片（按复习题目分别记录）在后台由 `ts-fsrs/FSRS-6` 维护以下参数（见 `src/types.ts` 与 `src/srs.ts`）：
  - 下次到期时间（`due`）、当前间隔天数（`interval`）、总复习次数（`reps`）、遗忘次数（`lapses`）、稳定度（`stability`）、难度（`difficulty`，新卡默认 0，调度后通常在 1–10）及学习状态（新卡 / 学习中 / 复习中 / 重新学习）。
  - 调度默认目标记忆保持率 `0.9`，短期学习步长 `1m`、`10m`，重学步长 `10m`。
  - 在卡片详情点「复习记录」可查看该卡的历史复习记录。
- **暂停 / 移出复习**（按源码 `src/review/decks.ts` 实际行为）：
  - 本插件没有单独命名叫暂停或搁置的按钮；如需让某张卡不再出现在复习队列中，请在「复习卡组」面板展开「卡组成员」，点对应卡片旁的「移出卡组」（或在浏览卡组时点「移出卡组」）。
  - 另外，被合并进父卡的组员卡片会自动标记为「合并组员 · 暂停单独复习」，隐藏卡片会标记为「已隐藏 · 暂停复习」，均不会单独出现在到期复习中。

## 9. 脑图

### 9.1 节点来源与自动进脑图

- **自动进脑图**：默认开启 设置 → MarginStudy → 阅读 → 「生成卡片自动进脑图」。学习集「摘录去向」为「后续摘录 · 跟随默认」时，取决于全局「生成卡片自动进脑图」开关（开启时同步建节点，关闭时仍成卡但不建节点）；设为「只留在文档」则覆盖全局开启、不建节点，设为「自动加入脑图」则会覆盖全局关闭。
- **手动加入 / 撤出**：关闭自动进脑图后，可打开「卡片分组看板」把卡片拖入脑图（会复制生成对应脑图卡片节点；普通卡片列表不支持拖拽），或在去向未设为「只留在文档」时点击区域摘录浮条中的「加入脑图」（仅区域摘录浮条提供此按钮）；点击已有批注的「撤出脑图」可仅移出脑图节点而保留文档标注。
- **外部导入**：支持从 Obsidian Canvas 导入为脑图（命令 ID：`import-canvas`）。

### 9.2 画布操作、拖拽与多选

- **平移与缩放**：在脑图空白处按住拖动或直接滚动滚轮可平移画布，按住 `Ctrl`/`Cmd` 滚动滚轮缩放。
- **拖拽节点**：拖动卡片节点可调整其在画布上的位置（拖拽节点不改变父子层级）。
- **多选**：按住 `Cmd/Ctrl` 单击多个节点，或按 `Cmd + Alt + M`（Mac 工作区）切换脑图多选模式；多选后可批量移动、打标签、合并卡片或加入复习。
- **关联线**：在「整理」场景点「链接」可进入连线模式，在两个不同卡片的节点间拉出关联线（同卡引用节点间与已有父子结构线有限制；新建连线默认不带文字，点击关联线可选择「断开此关联」或「取消」，界面不提供在连线上新增或编辑标签的入口）。

### 9.3 分支样式（10 种选项）

在脑图工具栏或设置（设置 → MarginStudy → 阅读 → 「默认分支样式」）中，可选择 10 种分支样式（来源 `src/types.ts` 的 `BRANCH_STYLES`；设置页和全局工具栏只保存全局默认样式偏好，常规绘线只读取节点自身单独设置的样式，因此未单独设样式的连线不会因全局切换而改变外观，也不会为 10 种选项各自重排不同方向的坐标）：

| 样式名称 | 样式 ID | 说明 |
| --- | --- | --- |
| 「向右」 | `right` | 默认分支样式 |
| 「向左」 | `left` | 分支样式选项 |
| 「双向」 | `both` | 分支样式选项 |
| 「鱼骨」 | `tree` | 分支样式选项 |
| 「逻辑图」 | `logic` | 分支样式选项 |
| 「经典」 | `mind` | 分支样式选项 |
| 「紧凑」 | `mini` | 分支样式选项 |
| 「向下」 | `down` | 分支样式选项 |
| 「组织架构」 | `org` | 分支样式选项 |
| 「时间轴」 | `timeline` | 分支样式选项（适合手动按时间排列，不自动按日期排序） |

### 9.4 折叠、子脑图与沉浸模式

- **单节点折叠**：点击节点旁的折叠图标（「折叠/展开」），或在节点菜单点「折叠」。
- **全部折叠 / 全部展开**：在脑图菜单中可执行「全部折叠」或「全部展开」，支持一键撤销恢复原折叠状态（处于按层级筛选视图时两项菜单禁用）。
- **子脑图**：选中单个节点，可在菜单中选择「创建子脑图…」「打开子脑图」「重命名子脑图…」「删除子脑图…」「塌缩成子脑图」「展开子脑图」。打开子脑图后可点「固定此子脑图视角」方便随时切回。
- **沉浸模式**：分为两种情况——在学习工作区中点「学习集更多设置」→ 「进入沉浸模式」进入工作区专注，按 `Esc` 或再点「退出沉浸模式」即可退出；在独立脑图窗口中点脑图工具栏「沉浸」会隐藏工具栏并同步开启「默认沉浸模式」，此时按 `Esc` 仅清除节点选择、不会恢复工具栏，如需退出请到 设置 → MarginStudy → 阅读 → 关闭「默认沉浸模式」后重新打开独立脑图窗口。

### 9.5 脑图导出

| 导出方式 | 入口 / 命令 | 产出格式 |
| --- | --- | --- |
| 导出为图片 | 脑图工具栏「导出图」，或命令「导出脑图为 PNG/SVG」（`export-mindmap-png`） | PNG / SVG |
| 导出为 Obsidian Canvas | 顶部「脑图」胶囊 → 「导出思维导图」，或命令「导出当前导图为 Canvas」（`export-canvas`） | `.canvas` |
| 导出单个分支或卡片 | 脑图节点菜单 → 「导出分支」/「导出本卡」 | 导出所选子树或单卡 |

## 11. 复习

### 11.1 复习卡组管理

- **入口**：命令面板运行「新建与管理复习卡组」（`manage-review-decks`），或在工作区点「学习集更多设置」→ 「管理复习卡组…」。
- **常用操作**：
  - 在「新卡组名称」输入框键入名称，点「新建卡组」。
  - 勾选「绑定到当前学习集」后点「使用此卡组」，使当前学习集默认关联该卡组。
  - 在「最长间隔（天）」输入框填入正整数并点「保存最长间隔」，可限制该卡组卡片的最大复习间隔（留空则使用默认 FSRS 调度）。
  - 展开「卡组成员」可查看全部成员或将单张卡片「移出卡组」；点「浏览全部卡片」可在不触发评分的情况下筛选、排序、朗读或编辑卡组内容。
- **自动加入复习**：在「回忆」场景底部工具栏点「自动加入复习」开关，开启后在阅读器新建的卡片会自动进入当前学习集绑定的复习卡组。

### 11.2 每日复习、错题与刷题练习

| 模式 | 命令名称（命令 ID） | 作用 |
| --- | --- | --- |
| 到期复习 | 「开始复习（到期的卡）」（`start-review`） | 默认按 FSRS 到期时间依次复习（学习集也可记住随机等其他排序），评分会更新复习进度 |
| 错题复习 | 「复习错题」（`review-wrong`） | 按题目筛选，只复习最近一次未撤销、非初始入队的正式评分为「重复」的题目（之后答对的题目不再出现） |
| 刷题练习 | 「刷题练习（不改变复习进度）」（`start-practice`） | 自由刷题检验掌握程度，不影响 FSRS 间隔与到期时间 |
| 文档忆模式 | 「切换忆模式（遮住摘录，点击揭示）」（`toggle-recall`） | 直接在阅读器正文里遮住高亮做主动回忆，点击单条揭示（启用「AI提示」时点击会先打开提示而非直接揭示）；「回忆」场景底部还提供「层级」「重置」「AI提示」「回忆设置」 |

### 11.3 复习界面操作与评分按钮

进入复习窗口后：
1. 先看题目；如需使用辅助工具，先点「批注与工具」展开工具区（内含「隐藏挖空」/「显示挖空」、「本次复习批注」、手绘草稿、「整卡截图批注」「空白手写」「朗读当前内容」等）。
2. 点底部「显示答案」（或按 `Space`）。
3. 核对答案后，如需回看上下文，可点「查看来源文档」或「查看所在脑图」（看完后点浮出的「返回复习」按钮回到原题）。
4. 点底部四档评分按钮（按钮上会实时预览各档下次间隔）：
   - **「重复」**（快捷键 `1`）：没记住，短期内重来，并标记为错题。
   - **「难」**（快捷键 `2`）：勉强想起时选择，实际间隔见按钮预览。
   - **「良好」**（快捷键 `3`）：正常记住，按标准间隔推后。
   - **「易」**（快捷键 `4`）：非常熟练时选择，按 FSRS 调度下次间隔（若卡组设置了最长间隔上限，实际间隔不超过该上限，以按钮预览为准）。
5. 如果按错了，展开「批注与工具」点「撤销上次评分」可立即撤回当前会话的上一题评分并重评。

### 11.4 学习统计

在命令面板运行「查看学习统计」（`show-stats`），可查看：
- 卡片总览：「总卡片」「· 闪卡」「· 摘录卡」「· 评论卡」「当前脑图到期」「已复习过」「标注总数」「导图节点」「关联线」。
- **「复习日历（近 17 周）」**：按天展示当日正式评分次数的热力图（同一张卡的多道题目分别评分时会分别计次）。
- **「复习间隔分布」**：按 `≤1天`、`2-3天`、`4-7天`、`8-14天`、`15-30天`、`31-90天`、`>90天` 统计当前脑图复习候选中（未标记访问、对应卡片仍存在且非合并组员）且已有复习状态的题目间隔分布（不限是否已到期；同一卡片的多道独立填空题分别计入，隐藏卡片若仍有匹配的待复习记录和状态也会计入）。

## 12. 搜索

MarginStudy 提供三层搜索入口，全部在本地完成：

### 12.1 全局搜索

- **入口**：工作区顶部放大镜图标（「全局搜索」），或命令面板运行「全局检索（卡片 + 批注）」（`global-search`）。
- **五个搜索分类**：
  1. 「脑图」：搜脑图节点标题及关联卡片内容，点击跳转对应学习集与脑图。
  2. 「文档目录」：搜当前打开文档的目录条目，点击跳转。
  3. 「文档正文」：搜当前打开文档的正文文字，PDF 点击直达对应页码（非 PDF 文档点击后仅关闭搜索面板，不做页内定位）。
  4. 「功能」：搜插件命令与设置项，点击直接执行或跳转定位。
  5. 「卡片与批注」（从命令面板或工作区「全局搜索…」进入时显示）：跨全库卡片与常规文档的 `.mstudy.json` 批注检索（跳过 `MarginStudyBackups/` 与 `_marginstudy-recovery/`），点击一键回源。
- **高级语法**（`OR` 与 `-` 排除仅适用于「脑图」「文档目录」「文档正文」「卡片与批注」，「功能」分类将其作为普通关键词）：
  - 空格分隔多个词 = **同时包含（AND）**，例如 `刑法 过失`。
  - 词之间写 `OR` = **包含任意一个**（仅内容分类生效），例如 `合同 OR 侵权`。
  - 词前加减号 `-` = **排除该词**（仅内容分类生效），例如 `物权 -抵押`。

### 12.2 页内搜索

- **入口**：在工作区按 `Cmd/Ctrl + F`，或命令「在 PDF 中搜索（Ctrl+F）」（`pdf-search`）；场景界面可在「文档 - 更多」→ 「文档内搜索」，传统界面在顶部工具条点「文档内搜索」。
- **操作**：`Enter` 下一处，`Shift + Enter` 上一处，`Esc` 关闭。

### 12.3 功能搜索（命令与设置一键定位）

- **入口**：全局快捷键 `Cmd/Ctrl + Shift + P`，或命令面板运行「功能搜索（设置与操作索引）」（`feature-search`）。
- **作用**：用中文关键词检索内置功能索引中的命令与设置项（如搜「侧栏」「备份」「自动高亮」；未登记的场景控件与工作区子设置不在索引中），`↑`/`↓` 选择，`Enter` 直接执行命令或打开设置页并高亮滚到该设置项。

## 13. AI 面板

### 13.1 入口

- 在工作区点「学习集更多设置」→ 「AI」（或传统界面右侧工具栏的闪光图标「AI 学习助手」）。
- 在文档拖选文字后，在选区菜单点「向 AI 提问」，会自动把选中文字附带进 AI 面板。

### 13.2 能做什么

1. **对话与单次提问**：自定义 API 模式下，顶部下拉框可切换「对话」（保留上下文多轮交流）或「提问」（单轮独立提问）；Claudian 模式会强制使用「对话」并禁用该下拉框。
2. **四种内置提问模板**（自动在提问前附加对应引导提示词，实际回复形式视所选模型而定）：
   - 「模板：引导模式」：提示 AI 用引导式问题帮助理解、先不直接给完整答案。
   - 「模板：测验模式」：提示 AI 出题检验理解、先不展示答案。
   - 「模板：解释模式」：提示 AI 解释核心概念并举例子。
   - 「模板：脑图」：提示 AI 将材料整理成脑图（自动切到「AI 目录」任务）。
   - 点「管理」可临时修改本次会话的模板提示词。
3. **四种任务类型**：
   - 「提问」：普通回答。回复下方提供「制作卡片预览」「回答转脑图分支」「选段写评论」「选段设标题」（使用「选段写评论」「选段设标题」需先在回复中选中一段文字，同时在脑图选中一个目标节点），且可直接把回答拖入脑图。
   - 「AI 目录」：生成可编辑的「目录预览」，确认后点「保存目录」写入当前学习集。
   - 「生成卡片」：生成可编辑的「卡片预览」，修改标题/正文/笔记/标签后点「保存卡片」保存到当前学习集（不会自动加入复习）。
   - 「识别为 Markdown」：生成「Markdown 预览」，点「另存为新笔记」保存为资料库中的新 Markdown 文件（同名不覆盖）。
4. **附加材料与「更多 AI 功能」**：
   - 点回形针图标（「附加文字或图片」）可选择「使用当前选择」「附加文字」「附加图片」（最多 4 张，单张不超过 9 MB 且整组总大小不超过约 9 MB，支持 PNG/JPEG/WebP/GIF；若使用 Claudian 且当前版本未支持图片直连，需在 Claudian 聊天中手动附加图片）或「粘贴 AI 回复」把外部 AI 回复转为可编辑预览。
   - 也可直接把卡片、文本或图片**拖放**进 AI 面板，或在输入框里粘贴图片。
   - 点「更多 AI 功能」→ 「对当前文档」或「AI 生成目录」，可提取当前文档文字作为上下文（PDF 按各页带编号的累计长度超过 180,000 字符时会提示改选部分文字，非 PDF 文档超过该长度会截断），附加后点击「发送」提交。

### 13.3 需要什么配置

AI 面板支持两种接入方式：

1. **「Claudian（现有插件）」**（若你的 Obsidian 已安装并启用 Claudian 插件）：
   - 面板检测到 Claudian 时会自动选中并提供「AI 服务」下拉切换；适配 `2.3.21` / `2.3.24` / `2.3.30` 版本，需 Claudian 运行时与当前所选模型可用才支持文字直连（图片直连仅 `2.3.30` 支持）；其他版本点「发送」会进入「在 Claudian 中继续」手动提问流程，不会直接送到模型后端。
   - 在 `2.3.30` 且 Claudian 回复 API v1、读取方法与工作区事件均可用时，还支持点击同步图标（「自动接收下一条 Claudian 回复」）自动回流回复。
2. **「自定义 API」**（兼容 OpenAI Chat Completions 接口，且支持流式 SSE、两个模型均支持图片输入，以及 Normal 模型支持工具调用与工具结果回传的服务或本地模型）：
   - 点面板中的「连接自定义 AI」或输入行左侧的「AI 设置」图标（也可在「学习集更多设置」→ 「自定义 AI…」打开）。
   - 依次填写：
     - **「Base URL」**：完整的 Chat Completions 地址（例如 `https://…/v1/chat/completions`）。
     - **「API Key」**：你的密钥（需当前 Obsidian 支持密钥存储接口；本地服务可留空；可勾选「清除已保存密钥」清除）。
     - **「Mini 模型」**：轻量任务使用的准确模型名称。
     - **「Normal 模型」**：常规及卡片/目录生成使用的准确模型名称。
   - 点「测试并绑定自定义 AI」，通过流式文本、图片与工具调用检测后即绑定生效。修改地址、密钥或模型后需重新测试绑定。

## 14. 导入导出

### 14.1 导入网页 / 微信文章与其他来源

- **导入网页 / 微信文章**：
  - 入口：顶部「文档」胶囊 → 「从Web」；或「学习集更多设置」→ 「导入网页 / 微信文章…」；或命令「导入网页 / 微信文章」（`import-web-article`）。
  - 用法：在「文章网址」填入 `http` / `https` 链接后点「导入并打开」，抓取正文与图片并转为可标注的静态 HTML；遇到抓取失败、需要登录或校验的页面，可尝试在浏览器打开页面后展开弹窗里的「粘贴 HTML 备用入口」，把页面源码粘贴到「网页 HTML」框中再点「导入并打开」（无法下载的图片会缺失）。
- **其他导入入口**（顶部「文档」胶囊）：
  - 「从资料库…」：打开主页「资料库」浏览并打开库内文档（点击仅打开并登记文档，不自动加入当前学习集；要显式加入当前学习集请用「管理文档…」）。
  - 「从文件」：从电脑文件系统导入文档到资料库。
  - 「新建笔记本」：创建空白学习笔记本。
  - 「从百度网盘」：通过百度网盘 OAuth 导入文档。
  - 「添加外部源」：登记本地外部文件夹路径（不会自动导入文件或加入当前学习集）。
  - 「导入学习集（.marginstudy-set.zip）」（命令 ID：`import-study-set`，或「学习集更多设置」→ 「导入学习集…」）：导入他人或旧设备导出的学习集压缩包。
  - 「从 Canvas 导入为导图」（命令 ID：`import-canvas`）：把 Obsidian `.canvas` 文件中的文本节点及文本节点间的连线转为 MarginStudy 脑图（文件、链接、群组节点会被跳过）。

### 14.2 PDF 导出与合并

- **导出编辑后的 PDF**：完成裁边、插页、旋转或删除页面后，通过顶部「文档」胶囊 → 「导出文档」，或在命令面板运行「导出编辑后的 PDF」（`export-edited-pdf`）导出新 PDF。
- **合并到另一份文档**：在「文档 - 更多」点「合并到另一份文档…」，可选择另一篇普通 PDF 或已有的重组文档（`.msref`）作为目标——选择普通 PDF 时会新建 `.msref` 引用文档，选择已有 `.msref` 时会将当前页面引用直接追加到该目标文档中，不会另建新文件。
- **导出 PDF 目录为笔记**：命令面板运行「导出 PDF 目录为笔记」（`export-pdf-outline`），把 PDF 书签目录导出为 Markdown 大纲。

### 14.3 笔记、Anki 与学习集导出

| 导出目标 | 命令名称 / 入口 | 命令 ID | 说明 |
| --- | --- | --- | --- |
| 当前文档 Markdown | 「导出当前文档为 Markdown」 | `export-markdown` | 导出标注、卡片与脑图树为 Markdown |
| 当前文档 HTML | 「导出当前文档为 HTML」 | `export-html` | 导出单个自包含 HTML 笔记 |
| 全库 HTML | 「导出全部学习库为 HTML」 | `export-all-html` | 汇总全库未隐藏且非合并组员的卡片导出为单个 HTML |
| Anki TSV | 「导出 Anki 兼容 TSV（当前文档）」 | `export-anki-tsv` | 制表符分隔的正反面与标签 |
| Anki APKG 牌组 | 「导出 Anki 牌组（APKG，含图片与遮挡）」 | `export-anki-apkg` | 导出含正反面、挖空、图片遮挡、媒体与标签的 APKG 文件供 Anki 导入 |
| 学习集备份包 | 顶部「脑图」胶囊 → 「导出学习集」；或「学习集更多设置」→ 「导出学习集备份」 | — | 生成 `.marginstudy-set.zip`，打包文档、批注、卡片、脑图、媒体与校验清单；另提供「导出学习集备份（不含 PDF）」（注意：不含 PDF 的备份无法自动恢复原 PDF 批注） |
| 笔记数据库 | 「学习集更多设置」→ 「导出到笔记数据库」 | — | 将学习集内容导出为笔记文件 |

### 14.4 备份、恢复与保存冲突处理

- **自动与手动备份**：
  - 默认开启 设置 → MarginStudy → 「每日自动备份」，每天首次启动插件时自动备份到 `MarginStudyBackups/`。
  - 随时可打开命令面板运行「备份数据（MarginStudy）」（`backup-data`），或在学习集主页点「版本库」→ 「立即备份」。
- **从备份或快照恢复**：
  - 运行「选择保护快照恢复对象」（`restore-backup`）或「查看本地状态与保护快照」（`local-sync-status`），也可在学习集主页点「版本库」→ 「从备份恢复选定对象」，按对象选择恢复，不盲目覆盖整库。
- **处理保存冲突**：
  - 当多设备同步或外部编辑导致磁盘上的 `data.json` 或 `.mstudy.json` 与当前基线不一致时，插件会暂停写入防止覆盖，并把恢复点保存在 `_marginstudy-recovery/`。
  - 打开命令面板（宿主默认 `Cmd/Ctrl + P`）运行「处理保存冲突」（`resolve-save-conflict`），针对「卡片、脑图与复习记录」或具体「文档批注」按需选择以下三种方式之一：
    1. **「合并，保留冲突内容为独立副本」**（需要同时保留双方不同内容时选择）。
    2. **「采用当前窗口版本」**（桌面暂存冲突时显示为「采用本地候选」）。
    3. **「采用磁盘版本」**（桌面暂存冲突时显示为「采用外部版本」）。

## 17. 数据与文件

MarginStudy 将学习库、文档批注与媒体文件保存在你自己的 Obsidian 资料库中（自定义 AI 的地址与模型配置保存在 Obsidian 本地存储，API Key 保存在 Obsidian 密钥存储）。除使用网页导入、百度网盘、AI 面板等联网功能，以及恢复工作区先前保存的研究浏览器辅助栏或独立的「研究浏览器」标签页/窗口（均会自动加载已保存的 URL）外，不主动对外发起请求。使用 AI 面板时，检测到 Claudian 会默认选中「Claudian（现有插件）」，其中适配 `2.3.21` / `2.3.24` / `2.3.30` 且运行时与当前模型可用时才会直接把提问、选区与受支持的图片交给 Claudian 所选模型后端，其他版本点「发送」只进入手动提问流程、不会直接发送到模型后端；若使用「自定义 API」，则会将提问、选区与图片发送到你填写的服务地址。

### 17.1 核心文件与目录一览

| 数据内容 | 存放位置 | 说明 |
| --- | --- | --- |
| 主学习库（卡片、脑图、学习集、复习记录、设置） | `.obsidian/plugins/margin-study/data.json` | 插件核心数据库 |
| 单篇文档的批注、高亮、区域摘录与手写 | 原文档同目录 `<原文档名>.mstudy.json` | 侧车文件；在 Obsidian 内重命名或移动文档时通常会同步迁移路径，但旧侧车与目标侧车同时存在时会停止迁移并提示冲突（仅目标侧车存在时会继续读取并更新关联） |
| 语音批注录音 | `_marginstudy-audio/` | 录制的音频文件 |
| 卡片图片与手写评论媒体 | `_marginstudy-media/` | 常规保存时仅将超过 64 KiB 的受支持内嵌图片外置到此目录，较小的图片仍内嵌保存在卡片或批注数据中 |
| 网页/外部导入文档 | `MarginStudyImports/` | 导入的 HTML 等文档及同目录 `assets/` 下载图片 |
| 自动与手动完整备份 | `MarginStudyBackups/` | 命名格式：`MarginStudyBackups/<YYYY-MM-DDTHH-MM-SS-sssZ>-backup-<36进制时间戳>-<随机串>/`，内含 `data.json`、`files/` 与校验清单 `manifest.json` |
| 保存冲突与本地保护快照 | `_marginstudy-recovery/` | 检测到外部修改冲突时保留的两份版本，以及处理冲突、恢复选定对象等操作前生成的保护快照（如 `protection-*.json`） |

### 17.2 如何迁移到新设备

- **方式一：整库搬家（适合迁移整个资料库）**
  1. 在旧设备先运行一次「立即保存学习库」（`save-now`）或「备份数据（MarginStudy）」（`backup-data`）。
  2. 把整个 Obsidian 资料库（包含 `.obsidian/plugins/margin-study/data.json`、所有 `.mstudy.json`、`MarginStudyImports/`、`_marginstudy-*` 目录及原文档）同步或拷贝到新设备。
  3. 在新设备确保插件文件齐全并启用 MarginStudy，打开资料库后检查文档与卡片是否正常显示。
- **方式二：只搬运单个学习集**
  1. 在旧设备顶部「脑图」胶囊点「导出学习集」（或「学习集更多设置」→ 「导出学习集备份」），保存为 `.marginstudy-set.zip`。
  2. 在新设备点「学习集更多设置」→ 「导入学习集…」（或命令「导入学习集（.marginstudy-set.zip）」），选择该 zip 文件导入。

## 18. 常见问题

### 1. 平板手写或划选时总把 Obsidian 侧栏滑出来？
- 检查 设置 → MarginStudy → 阅读 → 「阅读区禁止左右滑动开侧栏」是否已开启（默认开启）。
- 手写时建议先落触控笔再轻靠手掌；如设备系统提供仅触控笔涂鸦选项，可按需开启。

### 2. 底部或顶部工具栏遮挡正文怎么办？
- 点底部工具栏最左侧的收合按钮（「收合底部工具栏」）把底部栏收起。
- 按住顶部左上角的「简洁显示把手」半秒（或按 `Cmd/Ctrl + Alt + H`）进入简洁显示（进入后把手会移至顶部居中）。
- 确认 设置 → MarginStudy → 「隐藏宿主标签栏」已开启，减少顶部占用。

### 3. PDF 打不开或打开一片空白？
- 检查插件目录（默认 `.obsidian/plugins/margin-study/`）下是否缺少 `pdf.worker.js`。
- 如同时启用了其他第三方 PDF 插件（如 pdf-plus），可尝试暂时停用排查，或关闭「用 MarginStudy 替代原生阅读器」对比原文件在宿主查看器中的表现。

### 4. 高亮了文字，但右边没出现卡片或脑图节点？
请按顺序检查四项设置：
1. 设置 → MarginStudy → 阅读 → 「高亮后自动成卡」是否开启（区域摘录则查「区域摘录自动成卡」）。
2. 「自动摘录与成卡最短字数」是否设得太高（默认 4 个中文字符，划的字太短不会自动成卡；可调小或填 `0`）。
3. 「生成卡片自动进脑图」是否开启。
4. 场景界面顶部右侧的摘录落点是否误选成了「只留在文档」（改回「自动加入脑图」或「后续摘录 · 跟随默认」即可）。

### 5. 同步或外部编辑后弹出「保存冲突」？
- 这是正常保护机制，说明磁盘文件相对当前窗口基线已被外部修改（可能是多设备同步，也可能是本机另一窗口或外部程序修改），插件已暂停写入防止覆盖。
- 打开命令面板（宿主默认 `Cmd/Ctrl + P`）运行「处理保存冲突」（`resolve-save-conflict`），需要同时保留双方修改时可选「合并，保留冲突内容为独立副本」。

### 6. 缩放后短暂模糊，或平板打开大 PDF 渲染负担重？
- 捏合缩放时先显示几何预览、松手后按新比例重绘当前页，属于正常渲染流程。
- 移动端希望降低页面渲染像素预算时，可保持 设置 → MarginStudy → 「移动端降低 PDF 分辨率」开启；希望提高像素密度时，可关闭后重新打开 PDF。
- 希望手写预览包含一帧预测笔迹时，可在设置中尝试开启「手写笔迹预测」。

## 19. 故障排查清单

| 现象 | 检查项 | 处理步骤 |
| --- | --- | --- |
| 装好插件后左侧无书本图标、命令面板搜不到命令 | 插件目录路径、Obsidian 版本、宿主插件开关 | 确认目录位于当前 Obsidian 配置目录下的 `plugins/margin-study/`（默认 `.obsidian/plugins/margin-study/`，不要多套一层文件夹），Obsidian ≥ 1.4.0，并在宿主设置中启用第三方插件与 MarginStudy（安全模式名称与重启方式因 Obsidian 版本而异） |
| 修改了卡片或批注，重启后没保存 | 诊断模式开关、保存冲突 | 1) 检查 设置 → MarginStudy → 「停用持久化（仅诊断用）」是否误开，立即关闭；2) 运行「立即保存学习库」（`save-now`）；3) 若有冲突提示，运行「处理保存冲突」（`resolve-save-conflict`） |
| 文档改名或移动后卡片提示「来源缺失」 | 原文档是否仍在库内、是否已有指纹、两侧车是否冲突 | 若已有待处理候选，可运行「处理待恢复的原文档来源」（`recover-document-sources`）打开「待恢复的原文档」列表选旧路径与候选（此命令只显示已有候选列表，本身不触发扫描）；若文档已被登记为缺失且已有指纹，可运行「查看本地状态与保护快照」（`local-sync-status`）点「重新链接来源文件」自动扫描——有且仅有一个字节一致候选时会尝试自动迁移，若旧侧车与目标侧车同时存在、待保存恢复文件冲突或迁移异常，该候选会转入待处理列表（手动点该候选亦需先处理冲突）；存在多个字节一致候选或仅找到内容已变的同格式候选时，也会进入「待恢复的原文档」手动选择（内容已变时点「采用已变化内容：」对应项）；无候选时不会重连 |
| 拖选文字后没有自动高亮 | 界面模式与场景、工具、开关与最短字数 | 普通自动高亮需处于场景界面的「摘录」或「书写」场景且选中「文本」工具（非手形/手写/块选择），并开启「拖选文本自动高亮」且满足「自动摘录与成卡最短字数」；传统界面的普通文本工具不会因该开关自动高亮（但若此前已在 PDF 用「文本」工具开启「连续摘录」，切回传统界面后该文本连续摘录会话仍有效并继续自动高亮；矩形「连续摘录」不会自动高亮文本） |
| 点击「双页模式 (PDF)」呈灰色不可选 | 当前是否为「竖向阅读」 | 在顶部「文档」胶囊先切换到「翻页阅读」，再开启「双页模式 (PDF)」 |
| AI 面板无法点「发送」 | 是否已绑定自定义 AI 或选用 Claudian、输入是否为空 | 如用自定义 API，点「连接自定义 AI」填写 Base URL/模型并完成「测试并绑定自定义 AI」；确认已输入问题或附加文字/图片 |
| 手写「AI 转文本」失败 | 自定义 AI 绑定状态 | 「AI 转文本」依赖已绑定的自定义 AI 服务（且模型需支持图片识别），请先在 AI 设置完成绑定 |
| 扫描版 PDF 无法选字、点「识别当前扫描页」无效 | 操作系统、本地 OCR 组件与 OCR 开关 | 本地扫描识别仅支持 macOS，需本机配置识别组件且在「文档」胶囊 → 「PDF OCR设置」开启「Apple OCR Engine」；其他平台请改用「矩形」区域摘录截图 |
| 误删了重要卡片、脑图或批注 | 撤销栈范围、自动备份、保护快照 | 1) 刚误删卡片或脑图可立即按 `Cmd/Ctrl + Z` 或运行「撤销最近一次学习库操作」（`undo-library`）；部分文档批注删除（如区域摘录）走阅读器撤销（`Cmd/Ctrl + Z`），普通文字高亮删除未纳入该撤销栈；2) 若已关闭窗口或无法撤销，运行「选择保护快照恢复对象」（`restore-backup`）从 `MarginStudyBackups/` 或 `_marginstudy-recovery/` 恢复 |
| 网页导入提示超时或需要登录 | 抓取失败原因与目标网站限制 | 可尝试在浏览器中打开原网页，复制页面 HTML 后在导入弹窗中展开「粘贴 HTML 备用入口」，粘贴到「网页 HTML」框再点「导入并打开」（无法下载的图片可能缺失） |
| 脑图节点找不到或画面空白 | 脑图开关、画布缩放、沉浸模式 | 检查「学习集更多设置」→ 「显示/隐藏脑图」是否开启；切换顶部「脑图」胶囊确认选对画布；工作区专注按 `Esc` 退出，独立脑图沉浸需在设置关闭「默认沉浸模式」后重开脑图窗口 |
