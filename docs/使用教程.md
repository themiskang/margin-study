# MarginStudy 使用教程

给日常使用者准备的操作说明。不用懂代码，照着点就能上手。

MarginStudy 把「读 PDF → 划重点 → 变卡片 → 理脑图 → 复习」收进同一个 Obsidian 窗口，数据全部留在你自己的资料库。

![工作区预览](assets/preview-workspace.png)

## 一、5 分钟上手

1. **装插件**（需 Obsidian 1.4.0 及以上）：下载 `main.js`、`manifest.json`、`styles.css`、`pdf.worker.js`，放进资料库的 `.obsidian/plugins/margin-study/`。重启 Obsidian → 设置 → 第三方插件 → 关闭安全模式 → 启用 **MarginStudy**，左侧出现书本图标。
2. **打开 PDF**：在文件列表双击 PDF（或右键点「在 MarginStudy 中打开」），也可点左侧书本图标进入学习工作区。窗口自动左右分栏：左原文，右脑图。
3. **划重点**：在 PDF 拖选一段字，松手后在上方浮条点「高亮」或「下划线」。
4. **变成卡片**：默认会自动生成一张摘录卡，不用额外操作。
5. **看到脑图**：新卡片同时出现在右侧脑图。点一下脑图卡片，左侧立即跳回原文并闪烁定位。

## 二、日常用法

- **高亮与下划线**：拖选文字后点「高亮」「下划线」「删除线」或「批注」。点已有标注可转成摘录卡 / 评论卡 / 闪卡，或点「删除」。配色在「设置 → MarginStudy」修改。
- **手写与荧光笔**：电脑和平板都能手写，触控笔支持压感。点工具栏「手写」「普通笔 1 / 2」「铅笔」或「荧光笔」开写，点「手写层」分层整理；再点当前笔或切「手形工具」退出。
- **橡皮**：点「橡皮 / 橡皮擦」，划过笔画松手即整笔删除；误删按 `Cmd/Ctrl + Z` 撤销。
- **套索（移动 / 复制 / 删除）**：点「套索」圈住笔迹。按住选框拖动即可**移动**；浮出工具条依次有「颜色」「剪切」「复制」「AI 转文本」「删除」，扩展条有「转摘录」「解除绑定」。复制或剪切后按 `Cmd/Ctrl + V` 粘贴，`Delete` / `Backspace` 删除，`Esc` 取消。
- **折叠页与留白**：鼠标移到某页左上角，点「折叠 / 展开此页」可把整页收成窄栏，从脑图跳回时会自动展开。点阅读器顶部「留白 / 页边设置」可切换 `Normal` / `Margin` / `Collapse`、开关页边批注区，或点「添加留白」插入书写页。
- **双指缩放**：触屏上直接在 PDF 双指捏合缩放（30%–400%），手写、荧光笔、橡皮、套索态都能直接双指缩放；桌面端点工具栏 `−`、`+` 或「适应宽度」。
- **简洁模式**：按住工作区顶部居中的「简洁显示把手」约半秒，或按 `Cmd/Ctrl + Alt + H`，收起四周工具栏。手写态会自动留一条「精简笔条」（笔 / 荧光 / 铅笔 / 橡皮）。轻点把手或按 `Esc` 恢复。

## 三、卡片与复习

- **摘录进卡片**：「设置 → MarginStudy」默认开启「高亮后自动成卡」和「区域摘录自动成卡」。关掉后，点已有标注手动选「摘录卡」「评论卡」或「闪卡」。点开卡片可改标题、答案、标签、关键词或挖空。
- **卡片复习**：点工作区「学习集 → 复习」，或在命令面板（`Cmd/Ctrl + P`）搜「开始复习（到期的卡）」。先想答案，点「显示答案」（或按空格），可点「查看来源文档 / 查看所在脑图」回看上下文，再点底部 **重复 / 难 / 良好 / 易**（或按 `1`–`4`）排下次复习。命令面板还提供「复习错题」和「刷题练习（不改变复习进度）」。
- **看脑图**：默认开启「生成卡片自动进脑图」。空白处拖动画布平移、滚轮缩放；拖卡片调位置；按住 `Cmd/Ctrl` 单击可多选；拖中间分隔条调左右宽窄，或点分隔条箭头收起一侧。

## 五、数据在哪、怎么备份

| 内容 | 位置 |
| --- | --- |
| 卡片、脑图、学习集、复习记录、设置 | `.obsidian/plugins/margin-study/data.json` |
| 单篇文档标注与手写 | 原文档同目录 `<文档名>.mstudy.json` |
| 录音、图片与导入文件 | `_marginstudy-audio/`、`_marginstudy-media/`、`_marginstudy-imports/` |
| 自动与手动备份 | `MarginStudyBackups/` |
| 保存冲突保护快照 | `_marginstudy-recovery/` |

- **备份**：默认开启「每日自动备份」，也可按 `Cmd/Ctrl + P` 运行「备份数据（MarginStudy）」。
- **导出学习集**：点工作区「学习集 → 导出学习集备份」（或脑图菜单「导出学习集」），得到 `.marginstudy-set.zip`，打包文档、批注、卡片、脑图与复习记录。
- **换设备**：整库搬家只需在新设备装好插件并拷贝/同步整个资料库；只搬单个学习集则用「学习集 → 导入学习集…」（或命令「导入学习集（.marginstudy-set.zip）」）导入。

## 六、常见问题

1. **缩放后画面暂时不清晰？** 正常现象。缩放时会先显示快速预览防止卡顿闪白，松手后通常 0.2–0.5 秒内自动补画高清页。平板若嫌不够锐利，可在设置关闭「移动端降低 PDF 分辨率」后重开 PDF。
2. **平板手写时手掌误触？** 插件在触控笔落笔期间及抬笔后约 1.2 秒内会自动过滤手指/手掌触碰。建议先落笔再轻靠手掌，并开启平板系统的「仅触控笔手写」。
3. **PDF 打不开或打开一片空白？** 先检查 `.obsidian/plugins/margin-study/` 是否缺少 `pdf.worker.js`。如同时装了其他 PDF 插件，先停用排查，或在设置关闭「用 MarginStudy 替代原生阅读器」。
4. **中文 PDF 显示方块或乱码？** 插件已内置离线中文字体映射，断网可读常见中文 PDF。仍缺字多为文档未嵌特殊字体或是扫描图片；扫描页可点工具栏「识别当前扫描页」（仅 macOS，需另行安装识别组件，不含在插件包里）或用区域摘录。
5. **同步后提示「保存冲突」？** 说明磁盘文件被另一设备改过，插件已暂停写入防覆盖，快照存在 `_marginstudy-recovery/`。按 `Cmd/Ctrl + P` 运行「处理保存冲突」，按需选合并、采用当前窗口版本或磁盘版本。
6. **装好后左侧没图标、搜不到命令？** 确认目录名精确为 `.obsidian/plugins/margin-study/`（不要多套一层）、Obsidian ≥ 1.4.0，且在「设置 → 第三方插件」关闭安全模式并启用 MarginStudy 后重启。

## 七、已知限制

- **跳页后马上开目录栏，页码可能记为第 1 页**：不丢批注和卡片，跳页后稍等一秒再开目录即可避开；详见 [已知问题](known-issues.md)。
- **本地文字识别仅支持 macOS**：需另行安装识别组件（不含在插件包内），Windows 和移动端暂不支持本地识别。
- **不含 PDF 的学习集备份无法自动恢复原 PDF 批注**：跨设备迁移请用完整学习集备份或整库备份。
- **部分高级工具在二级菜单**：PDF 更多菜单只放常用入口，其余在「学习集 → 工作区设置… → 阅读与批注的全部工具」。
- **手机小屏与第三方主题**：手机端空间较紧，精读与手写建议用电脑或平板；部分社区主题可能影响参考层半透明笔迹深浅。
