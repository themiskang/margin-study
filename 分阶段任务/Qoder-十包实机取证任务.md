## 3. 十包最小取证矩阵（P0 = 必做；P1 = 有余力）

### 01 Extend
P0：
1. 同一 PDF 创建一条留白+文字+卡片（合成内容），截 MN4 / 插件同状态。
2. Normal / Margin / Collapse 三模式各一对（纸面比例、工具避让、高度柄）。
3. Advanced/Favorites/Basic 菜单全展开各一张；颜色/收藏/垃圾桶状态。
4. 独立评论区（有内容/空/禁用）各一对。
5. Export Card 弹层（格式/范围/选项）一对。
6. 已知缺口：MN4 修改裁剪、文字缩窄/最小尺寸、跨类型排序——各尝试一次，截成功/失败/恢复；不要伪造。
P1：图片/相机插页、来源摘录评论、虚拟页底部跳转、自动展开确认。

### 02 PDF
P0（详见 `02-Qoder-MN4截图任务.md`）：
1. 导出入口/选页（全选/页码/Annotated/Clear）/格式 PDF/Long Image/原生 Save 面板。
2. 长图：l4 4 页、mixed 3 页、long-30 页；记录尺寸、页序、页间距/背景/是否拆分。
3. 旋转 90/180/270（原版按钮），导出是否反映。
4. 裁边：页内点不恢复 vs 对角零面积点恢复；各 4 步截图。
5. PDF 插页：从 mixed 插入一页，记录位置/顺序/重开。
6. 复杂 PDF：压平导出后重开，检查 Link/Highlight/表单/目录。
7. Annotated 选页 + 组合编辑导出。

### 03 阅读器与文档工具
P0：
1. 阅读 Settings 全部页签/关键项（主题、布局、缩放、翻页）一对。
2. 单页/连续/双页布局各一对；缩放后重开定位。
3. 精确选择：单行、跨行、重叠高亮、双栏（two-column.pdf）各一对；扫描页/双页能测则测。
4. 目录编辑/拖动/重排（MN4 可观察入口）一对；TOC 生成/编辑。
5. Word/HTML：重排、导航、摘录回原文、切换重开定位（用 docx/html 输入）。
6. 自由元素：旋转/图片裁切/音视频添加-播放-缺源反馈各一对。
P1：AI TOC、目录编辑完整规则、媒体格式边界。

### 04 卡片模板与组织视图
P0：
1. 同一内容 3 张卡：不同模板/字段；编辑器 + 预览一对。
2. 脑图/大纲/看板三布局同内容各一对。
3. 多选/折叠/连线/引用/拆分/合并/层级拖动的菜单与结果；引用 vs 副本视觉区分。
4. Undo/Redo、删除恢复、保存重开无残留。
4. **Note Card 编辑器口径取证**：打开编辑器瞬间底部格式栏是否可见（不点正文）；点击正文/来源后是否出现；手写批注插入后是正文内联图片还是独立附注媒体。用于 Codex 决定 `review-ui` 的两处断言口径。

P1：跨脑图迁移、复杂层级、模板字段边界。

### 05 卡组与复习
P0：
1. 卡组列表 → **浏览页（问答评分之前的底栏）** 一对（重点）。
2. 问题页、答案页、四档评分、完成页各一对；首张/末张/空组。
3. 筛选/模板/成员刷新；遮挡/字词卡；到期/历史/统计页。
4. 保存重开与复习状态独立（复制/刷新不污染）。
P1：FSRS 参数/权重差异、错题、完成页动画。

### 06 Claudian AI
P0（验收库无 API）：
1. AI 入口/面板/模板/提问框；无 API/失败/取消/超时状态各一张。
2. 草稿保留、取消不导入、重复导入防护的 UI 状态（不伪造真实回答）。

### 07 研究网页

3. 动态页/登录受限页各一例，记录可用/受限原文。
4. 切换/重开恢复目标、历史、设置（前后各一对）。

### 08 系统能力与硬件
