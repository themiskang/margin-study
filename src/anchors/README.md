# 阅读锚点约定

新建 PDF 文字批注和区域摘录存 `pdfCoordinateSpace: "pdf"`，所有矩形均为 PDF.js `convertToPdfPoint` 返回的原 PDF 用户空间。CropBox 偏移、页面旋转和 PDF.js 的 Y 轴约定均由 viewport 处理，渲染调用 `convertToViewportRectangle`，不再额外翻转 Y。实际 canvas 的 CSS 尺寸与浮点 viewport 尺寸单独换算，避免取整和设备像素比例造成偏移。

跨页批注在 `pdfGeometry` 按页保存矩形，`page/rects` 同时保留第一页作为既有接口的兼容入口。每个页面分别管理覆盖层，所有分段保留相同批注 ID，因此删除、重新绘制、共享和揭晓仍指向同一条批注。该字段是本插件公开数据结构，不复制 MarginNote 私有的 startpos 字符串编码。

没有坐标空间标记的旧 sidecar 继续按旧的显示页坐标解释；不会假设旧旋转页已经是原 PDF 坐标，也不会静默改写旧数据。旧数据跨修改页面旋转后的重新锚定不在这一兼容承诺内。

PDF 来源跳转在展开目标页和渲染之前记录当前视图位置。目标文字可在 ±2 PDF 点容差内与引用矩形相交，命中后按文字行带垂直居中；没有文字层时按引用矩形居中。工具栏可返回或前进到先前位置，历史仅在当前阅读视图会话内保存。

HTML/EPUB 文字引用仍按章节、exact、prefix、suffix 找唯一最佳匹配。新批注额外记录本插件定义的章节内垂直 `sectionRatio`（0..1）。文字失配或有歧义时，这个比例只能导航到近似位置并明确提示，不能生成猜测高亮，也不能删除批注。该单位是本插件约定，原版 MarginNote 百分比量纲仍未确认。

阅读器使用公共控制器的遮挡会话，几何与持久 `Card/当前画布节点.occluded` 分离。工具栏默认遮挡全部摘录，也可切换为仅遮挡已标记的摘录；该范围仅影响当前视图。普通摘录的跨页/跨文字节点分段默认共用 `excerpt:批注ID`，揭晓后重绘仍保持，再点可收回；当前画布的 singlePeek 开启时只保留当前摘录。退出/重新进入忆模式、切换范围、文档或画布会清空临时揭晓，持久遮挡布尔值继续保留。

这些行为依据 Qoder 的 L3 静态调用链契约实现，并通过隔离浏览器与合成文档验证。测试不会操作真实笔记库，也不构成原版 MarginNote L4 验收。
