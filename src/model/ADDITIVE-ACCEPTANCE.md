# 新增批注与脑图手写数据验收

`node src/model/additive-acceptance.mjs` 使用真实 Store 与备份哈希、合成内存文件，12 项检查通过：[结果](additive-acceptance-evidence/results.json)。不读取或修改真实库。

- 旧批注兼容；自由文字、光栅图片、软删除、文档笔记本身份和高亮笔字段可保存重开。
- 软删除可撤销重做，保留原批注 ID 和卡片来源身份。
- 加载、编辑、冲突采用和备份恢复均检查批注身份、基本格式与新增字段；拒绝越界位置、无效样式、非布尔删除状态和 SVG/外部图片链接。
- 无效文件保持原字节；哈希正确但内容无效的备份在写入前拒绝；有效本地版本仍可用于解决冲突。
- 纯手写脑图算作有效学习内容；手写 patch 深拷贝、笔画撤销重做与持久化均通过。
- 未知手写格式版本会拒绝加载或更新，避免自动丢弃后覆盖；有效 version 1 使用规范化函数恢复有效笔画和层。

这份验收覆盖模型边界。手写工具操作、批注移动缩放及文档渲染由各界面模块另外验收。
