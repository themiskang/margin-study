# 手写编辑约定

笔迹继续使用相对所在页面/正文的 0..1 坐标。`Stroke.pressure` 可选；触控笔实际事件保存压力并显示分段粗细，鼠标和无压力旧数据保持等宽。

画笔逐笔提交；自由荧光笔以独立 `inkBrush: "highlight"` 保存和渲染，整条笔迹以 32% 不透明度显示；橡皮划过任一线段后删除整笔；手写套索按多边形与笔画相交选中，拖动平移，Delete/Backspace 删除选中笔画，Esc 取消。原有区域截图摘录是另一个独立按钮。套索平移以整组选中笔迹共同约束边界，不逐点裁切造成变形。

撤销/重做只管理当前视图、当前文档的手写和独立文字/图片批注，两类各保留最近 40 次操作。共享时序日志按单调序号记录新笔画、橡皮、移动、删除和自由批注编辑；原独立工具栏按钮及聚焦元素的 Cmd/Ctrl+Z 仍按对应类别回退。其他视图已改变相关数据时拒绝旧撤销并清空整个日志，避免覆盖新编辑。

笔画编辑写入原 Annotation.strokes，不更改来源 ID。完全擦空后保留空笔迹标注元数据，以保持已经关联的卡片来源 ID，并支持撤销；空笔迹不渲染覆盖层。关闭/切换时提交尚未抬起的画笔，未完成的橡皮/套索编辑取消。回收 PDF 页面只移除对应页的手写控制器。

当前套索支持平移和删除，不支持旋转/缩放。正文重排后的笔迹仍按归一化位置显示，未做语义重锚。这些交互是开发副本的独立实现；不能作为原版 MarginNote 的 L4 行为证据。硬件触控笔与真实宿主尚未在本验收中测试。

手写层元数据位于 DocMeta，笔迹及独立文字/图片批注通过 Annotation.inkLayerId 关联；旧笔迹缺少层信息时属于永久保留的默认层。切换当前层影响笔迹和自由批注，既有文字/区域摘录继续显示。允许叠加一个非当前层，以 35% 不透明度、禁止指针编辑的方式呈现，并在回忆模式下隐藏。

当批注携带的 `inkLayerId` 指向已删除或不存在的手写层（孤儿 `inkLayerId`）时，加载、切层、渲染与导出均不抛异常、不删除对象、不静默改写为其他层：按确定性降级回退到公共层可见（渲染 `alpha=255`、非参考态、导出 `opacity=1`），保留原 `inkLayerId` 与 `bindToInkLayer` 绑定意图供用户重新绑定或删除，且不参与正常层的合并、删除或新笔迹自动宿主绑定，避免污染正常层。

切换/新建/删除/合并图层前先结束旧画笔，未抬笔的笔迹按控制器创建时的图层提交。跨视图订阅同步当前层与叠加层，切层清除本视图手写及自由批注撤销记录，防止撤销越过工作层边界。改为已有层名执行合并，保留原批注身份和卡片来源；默认层即使合并为空仍存在。删除非默认层前显示确认；确认后清空该层笔迹、软删除该层自由批注并移除层列表项，保留来源元数据，不把删除图层操作加入撤销栈。

手写工具可双击打开手写设置；阅读器公开 `openHandwritingSettings(anchor?)` 供工作区统一工具栏使用。标题、Sketch Layers 分组、右侧勾选、列表/新建顺序、透明背景和顶部锚点参考已采集的原版运行时截图 08/09；图层新建、叠加、编辑/更多、重命名或合并、删除行为依据正式手册。合成界面和图标适配器不证明真实宿主或像素完全一致。

文档手写设置提供会话内的“消失笔”开关。开启后，普通画笔落笔只在当前页面覆盖层保留约 4 秒，然后移除；临时笔画不创建 Annotation、不进入共享撤销/重做或导出链路，也不改变既有永久笔迹。该开关和临时层在切换文档或关闭阅读器时清理。现有人工证据只验证文档空白处一支笔的短暂可见与消失，未验证跨脑图、Card 同步或在宿主重启后的设置持久化。

文档笔记本以 `Annotation.documentNotebookId` 隔离整套摘录/笔迹/语音/备注，继续使用真实源路径与同一 sidecar。非默认本的手写图层及视图状态保存在 `DocMeta.documentNotebookMeta`，主本兼容旧顶层字段。只读叠加本按其自己的手写层状态显示；HTML 参考文字批注采用绝对几何覆盖，避免嵌套包裹活动本的原文，支持字号/宽度重排后重定位，回忆隐藏不影响正文。来源回跳先切到所属笔记本，笔画在控制器创建时捕获笔记本/层 ID，未抬笔切本也不迁移笔迹。

三类阅读器公开 `getHandwritingMode()`、`setHandwritingMode(mode)`、`subscribeHandwritingModeChange(listener)`，模式为 `pen | highlight | eraser | lasso | off`。模式 setter 幂等，off 拆掉真实输入覆盖层并取消待放置自由批注；订阅只在变化时通知，不立即回调，返回退订函数。`DocMeta.handwritingSyncEnabled` 是文档级偏好，get/set/subscribeHandwritingSyncPreference 读取/保存/订阅该偏好（偏好订阅立即回调）。工作区连接阅读器与脑图的真实模式 API 后调用 `setHandwritingSyncAvailable(true)`，设置复选框才可操作；独立阅读器未连接时明确禁用。这里同步的是工具模式，笔迹分别保存在各自页面/画布；阅读器合成验收不代替工作区联动验收。

## 独立文字与图片批注

三类阅读器提供 `beginTextAnnotation()` 与 `insertImageAnnotation(file: File)`。稳定工具名为“文字批注”和“插入图片批注”；选择真实本地图片后再点击文档放置，不调用区域截图。支持 PNG/JPEG/GIF/WebP/AVIF、20 MB 以内、解码后不超过 6400 万像素，拒绝 SVG、空文件及无法解码的数据；图片保存在 sidecar 中。

自由批注沿用 `Annotation.type: "note"`，由 `overlay.kind` 区分文字或图片。PDF 的框使用 canonical `rects/pdfGeometry`，旋转 CropBox 与缩放均经 PDF.js 几何转换；HTML/Word 使用 `overlay.box` 的正文归一化位置，跟随正文宽高重排。文字内容为纯文本，可调字号/颜色/白色背景；图片可通过独立文件选择器替换。元素可拖动、角点缩放、双击编辑、删除、生成带原批注 ID 的来源卡片；文字/图片没有伪造原文选区。

创建/编辑/移动/缩放/替换/删除保留该类最近 40 次撤销/重做，提供专用工具按钮与聚焦元素时的 Cmd/Ctrl+Z。手写和自由批注共用时序日志，`undoLastEdit()`/`redoLastEdit()` 按最近操作回退/重放；新操作无论属于哪一类都会清空全部重做分支。删除为 `overlay.deleted` 软删除，保留来源 ID、已有卡片与图片数据；撤销恢复原对象字段，不覆盖卡片关联。层/本/文件切换及任一类别过期冲突都清空两类历史。重建正文、PDF 页面回收和文档释放清理指针手势及待放置状态；异步图片读取捕获文档修订与图层，切换后不会误写新位置。

工作区使用 `getEditHistoryState(): {canUndo,canRedo,undoLabel?,redoLabel?}`、`undoLastEdit()`、`redoLastEdit()`、`subscribeEditHistory(listener)`（立即提供状态并返回退订函数）。标签明确为“手写”“自由文字批注”或“图片批注”；界面应称“撤销手写和自由批注”，不能声称包含普通文字高亮/区域摘录的增删、文档布局或文件操作。原 `undoPenChange`/`undoOverlayChange` 等方法是共享日志的按类别视图；类别选择性重做会成为最近操作。

自由文字/图片继承当前手写层与文档笔记本，叠加层/本只读且在回忆中隐藏。普通文字/区域摘录保持原来的编辑通路。HTML 的自由元素不参与原文文字偏移与朗读。短正文只允许在其实际正文区域放置，当前不扩展无限画布；图片暂不提供裁切、旋转或流式音视频插入，文字缩放框改变框大小，不自动调整字号。新增编辑器尚未与原版对应操作逐项 L4 核对。
