# 连续朗读约定

`speech.ts` 提供无 Obsidian 依赖、可注入语音引擎的连续队列。每个阅读器/复习窗口创建自己的 session；共享协调器使新朗读停止旧所有者。闲置窗口的 stop/dispose 不会取消其他窗口正在播放的内容。

文字按句末/空格分成至多 220 个 UTF-16 字符的短段（保留 emoji 边界），无 3000 字截断。PDF 逐页异步取文字层；HTML/EPUB/Markdown/Word 按章节或正文提取文字，排除批注控制和语音按钮。暂停/继续、停止、0.5–2.5 倍速度可用于全部阅读器。调速时从系统最近提供的边界继续；系统不提供边界时重读当前短段。

切换文档、重载与关闭都停止当前阅读器 session。异步来源即使忽略 AbortSignal，也不能延迟 stop 的返回或在旧文档继续发声。所有语音属于用户明确开始的当前窗口会话，不写入学习数据。

`speechControls.ts` 是阅读器共用工具栏。复习窗口可直接使用 `createSpeechSession` 并根据题面/答案状态提供允许朗读的文本。

这些实现依赖宿主 Chromium 的 Web Speech 与系统声音。合成验收已覆盖队列行为，真实 macOS 声音、发音和复杂 PDF 多栏语序仍需宿主实测。系统朗读不是音频文件导出。
